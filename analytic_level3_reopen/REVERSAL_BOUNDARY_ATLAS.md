# Reversal Boundary Atlas

The symmetric reversal region can change only across a finite collection of
algebraic or regime surfaces after denominator clearing.

| Boundary | Defining object | Status |
|---|---|---|
| participation singularity | `u H = 0` | exact |
| participation regime | `0<s<t<1`, positive masses/benefits | exact rational inequalities |
| private stationary boundary | reduced private FOC = 0 | exact |
| private SOC boundary | `Pi_pp=0` | canonical sign certified; primitive projection not completed |
| B3 public FOC | B3 reduced FOC = 0 | exact polynomial system |
| B3 SOC boundary | reduced own numerator = 0 | canonical sign certified; primitive polynomial system available |
| B3 cross boundary | reduced cross numerator = 0 | canonical sign certified; primitive polynomial system available |
| G public FOC | augmented-system reduced FOC = 0 | exact; canonical elimination completed |
| G SOC boundary | reduced own derivative = 0 | canonical sign certified exactly; full primitive elimination pending |

| matched-price coupling | common algebraic `p_G` in G and B3 systems | canonical coupling certified by rational Krawczyk system; direct global resultant route timed out |
| discriminant surfaces | repeated roots / component collisions | partially computed through factor/discriminant structure |

The important geometric conclusion is that there is no evidence of
non-characterizability: the boundary set is algebraic/semialgebraic. L3-1
settles the canonical coupled branch and its sign side exactly. The remaining
difficulty is computing the complete primitive projection and separating
admissible from extraneous branches uniformly over parameter space.
