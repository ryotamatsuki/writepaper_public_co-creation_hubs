# Stage 1R-M Choice-Unit Coding Manual

## Purpose
The failed Stage 1R unit (`prefecture-year union of all intermediation`) is permanently rejected as an architecture-choice observation. Stage 1R-M separates the regional-state unit from the architecture-choice unit.

## Regional-state unit
`prefecture × year` is used only for predetermined/contextual regional conditions `z_rt`. H and P are never unioned at this level.

## Architecture-choice unit
Primary unit: `principal × portfolio/commissioning episode`.

A unit is valid only if all six conditions are met:
1. **Principal**: an identifiable public principal or governing coalition can authorize the portfolio.
2. **Decision opportunity**: a dated decision, procurement, launch, renewal, agreement or budgeted program exists.
3. **Common boundary**: H/P functions coded together belong to the same program, contract, concession, portfolio or governing decision.
4. **Governance attachability**: operator/control/funding information can be attached to this unit.
5. **Temporal identity**: start, renewal, procurement or material amendment year is identifiable.
6. **No cross-principal aggregation**: independent programs are never added together to manufacture HP.

## Functional architecture
- `H=1` only if at least two recurrent/core local functions are documented: local partner search, matching/brokerage, project formation, sustained mentoring or local coordination.
- `P=1` only if a recurrent explicit extra-regional function is documented: outside-prefecture/national partner brokerage, external expert/investor recruitment, international network or systematic external-resource import.
- Generic openness, one guest speaker, a broad member list or an aspirational mission alone is insufficient.

Architecture is derived mechanically:
- H=0, P=0 -> `0`
- H=1, P=0 -> `H`
- H=0, P=1 -> `P`
- H=1, P=1 -> `HP`

`HP` means co-provision, not complementarity.

## Zero rule
`0` is not absence of a famous hub. It requires a documented policy/commissioning opportunity in the innovation/startup-support domain where an identifiable principal chose an alternative instrument (e.g. grant-only financial support) but did not commission H or P within that bounded program.

A zero is rejected if it is based on missing webpages, unknown services, or arbitrary exclusion of related services within the same portfolio.

## Double coding
Coder A applies the functional threshold. Coder B applies the same threshold with a stricter geography/boundary reading. Disagreements are adjudicated from primary-source wording. Agreement statistics are diagnostic and are not represented as human inter-rater reliability.

## Theory discipline
Observed `R_j` is a decentralized institutional choice candidate. Stage 1R-M does not define, infer or estimate `R^SP`, welfare, payoff functions or a mechanism.
