# Stage 3R Feature-Stripping Test

## Test 1 — Remove L/X multidimensionality
- M-A still differs from integrated choice if bounded units have restricted actions. Therefore the distortion does not require two-dimensional regional state.
- M-F still misselects only if scope removes an action/state dimension. Hence one-dimensional versions can exhibit the same imposed error.
- M-D can still exhibit substitution neglect if substitution is assumed; L/X is not essential.

**Result:** `FAIL ESSENTIALITY`.

## Test 2 — Remove bounded scope
All scope-based candidates converge to integrated/componentwise choice. The distortion disappears.

**Interpretation:** P3 is necessary to the proposed narratives, but this is not sufficient evidence of a mechanism because P3 directly defines the action partition. A variable can be necessary because the outcome was encoded into its definition.

## Test 3 — Merge decision units
M-E distributed aggregation disappears and M-B becomes ordinary component choice. Any remaining inefficiency would require a cross-task externality, objective difference, information difference or shared resource constraint.

**Result:** distributed-unit mechanism is generic coordination unless a new primitive is added.

## Test 4 — Remove sequencing
M-C reduces to static componentwise/bounded choice. The observed evidence establishes modular additions but not a payoff consequence of order.

**Result:** sequencing is not evidence-essential.

## Test 5 — Replace H/P with generic tasks A/B
All proposed mechanisms can be restated without region, innovation, hub or pipeline language:
- bounded units choose task A/B;
- integrated organization chooses the task portfolio;
- split organizations may omit/duplicate/select different tasks.

This maps directly into generic policy integration, organizational-form, delegation and decision-architecture literatures unless an additional region-specific payoff interaction is introduced.

**Result:** `FATAL LABEL-STRIPPING FAILURE`.

# Overall stripping conclusion
The only feature that consistently remains essential is bounded scope itself. Multidimensional regional state does not do indispensable economic work in any candidate under the frozen primitive set. Therefore the desired `P1/P2 × P3` interaction is not identified.
