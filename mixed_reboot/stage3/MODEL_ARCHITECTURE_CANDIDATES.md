# Stage 3R Model-Architecture Candidates

## A — Integrated Single-Principal Architecture
One principal chooses `R in {0,H,P,HP}` directly.

**Evidence fit:** can represent individual bounded episodes, but it does not naturally represent same-principal menu variation or modular P additions unless each episode is treated as a separate one-shot problem.

**Strength:** minimal, transparent benchmark.

**Kill risk:** collapses the empirical decision-unit structure back toward the old unitary-actor representation.

**Status:** BENCHMARK ONLY.

## B — Componentwise Modular Choice
One principal chooses `h in {0,1}` and `p in {0,1}` separately, with realized architecture `(h,p)`.

**Evidence fit:** naturally represents H/P separability, P-only and HP without assuming complementarity. Same principal can choose different component pairs across bounded tasks.

**Strength:** minimal modular representation.

**Kill risk:** absent a cross-task payoff/information/resource wedge, separate component choice implements the same composition as integrated choice. Any nontrivial distortion therefore requires an additional primitive.

**Status:** SHORTLIST.

## C — Sequential Modular Architecture
A principal chooses a base module and later adds/does not add the other module.

**Evidence fit:** OIH GLOBAL BRIDGE and Saga Connect+ show modular additions.

**Strength:** can represent observed additions.

**Kill risk:** evidence establishes modularity, not that sequential timing is essential. Path dependence or irreversibility would be an unauthorized new primitive. Removing sequencing collapses the candidate into B/D.

**Status:** KILL — unnecessary timing feature.

## D — Bounded Portfolio / Task-Specific Choice
A principal faces bounded decision opportunities `j=1,...,J` and chooses `r_j in {0,H,P,HP}` inside each documented portfolio boundary. A regional architecture could later be mapped from the set of decisions, but Stage 3R does not impose an aggregation function.

**Evidence fit:** strongest. This is the actual Stage 1R-M measurement architecture and directly represents Tokyo/Okayama/Saga menus, NEXs P-only and modular P programs.

**Strength:** separates regional state from institutional choice and avoids researcher-created region-wide unions.

**Kill risk:** scope alone is not an economic wedge. If a unit has common objectives/information and a sufficient action set, boundedness need not distort choice. If its action set excludes alternatives, any misselection is mechanically imposed.

**Status:** TOP SHORTLIST.

## E — Hierarchical Architecture
An upper principal sets portfolio scope/authority and a lower unit chooses H/P content within it.

**Evidence fit:** some real programs use delegation, but Stage 2R found governance labels do not determine architecture.

**Strength:** interprets P3 as authority allocation.

**Kill risk:** introduces hierarchy not required by the core evidence and maps closely to Aghion–Tirole/control-rights and standard delegation theory.

**Status:** KILL — excess structure / prior-art collapse.

## F — Multiple Bounded Principals
Multiple public or quasi-public decision makers in one region choose bounded modules; regional architecture is an aggregate of their choices.

**Evidence fit:** consistent with the failed prefecture-year union showing that regions contain multiple decision makers.

**Strength:** can represent duplication and omission at system level.

**Kill risk:** same-principal variation already shows that multiple principals are not required to obtain H/P/0 diversity. To make independent choices inefficient requires cross-unit externalities, objective differences or coordination costs—new primitives and mature coordination/public-good theory.

**Status:** KILL — generic fragmentation risk.

## Stage 3R-A shortlist
1. **D — Bounded Portfolio / Task-Specific Choice**
2. **B — Componentwise Modular Choice**

A is retained only as the integrated benchmark/counterfactual. C, E and F are killed before mechanism selection.
