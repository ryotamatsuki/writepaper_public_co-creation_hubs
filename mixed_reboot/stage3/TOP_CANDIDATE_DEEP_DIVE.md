# Stage 3R Top Candidate Deep Dive

## Candidate 1 — D × M-F: Bounded portfolio with scope-state mismatch

### Why it looked strongest
- Directly matches Stage 1R-M choice units.
- Preserves P-only and same-principal H/P/0 menus.
- Uses both local/external state language and portfolio scope.
- Can be stated without assuming H/P complementarity.

### Two-by-two essentiality test
| Regional state | Integrated scope | Bounded/split scope |
|---|---|---|
| One-dimensional | integrated choice | any error requires restricted actions/objective/information |
| Two-dimensional L/X | integrated choice conditions on both states | proposed mismatch only if scope removes an action/state or an extra cross-task payoff wedge is added |

The bottom-right cell is not uniquely capable of generating misselection. If bounded scope literally excludes an alternative, a one-dimensional version also misselects. If bounded units retain all payoff-relevant information and aligned objectives, no wedge follows from dimensionality alone.

### Fatal diagnosis
P3 describes the boundary of authority, not why the holder of that authority chooses an inefficient action. A scope boundary becomes an economic mechanism only when paired with another feature: localized information, specialized objectives, cross-task returns, shared capacity, externalities or another delegation/incentive wedge. Those are not authorized.

### Label stripping
Two state variables A/B and two tasks X/Y are divided across bounded decision scopes. The organization can make a different task selection from an integrated chooser only because the bounded scopes eliminate choices or because an additional interdependence/information/incentive feature is introduced. This is generic organization design, not region-specific economics.

### Verdict
**KILL — primitive insufficiency / imposed distortion.**

## Candidate 2 — D/B × M-D: Portfolio-level substitution neglect

### Why it looked promising
It could generate over-composition (HP when H or P alone would suffice) as well as omission. This is closer to the original motivation than a pure underinvestment story.

### Fatal diagnosis
To define “substitution neglect,” H and P must overlap in their returns, consume a common scarce resource, or have a negative/positive cross-effect. None of these relations is contained in P1 local state, P2 external state or P3 decision scope. Adding such a relation would reopen the Stage 2R primitive gate. Without it, H and P are just two separable component decisions and there is no substitution to neglect.

### Verdict
**KILL — needs unauthorized cross-task primitive.**

---

## Candidate 3 — B/C × M-C: Sequential scope dependence

### Why it looked promising
The Japanese evidence includes modular P additions after existing support structures.

### Fatal diagnosis
Observed chronological addition does not imply that an earlier H choice causally changes the return or feasibility of P. For sequence to matter economically, the model needs irreversibility, learning, state transition, sunk investment or commitment. Those are additional primitives. If sequence does not change payoffs or feasible actions, the game reduces to static componentwise choice.

### Verdict
**KILL — sequencing is not mechanism-essential and would require a new dynamic/commitment primitive.**

# Common impossibility logic
Under the frozen primitive set, take an integrated benchmark and a modular decomposition. If each component decision has the same payoff-relevant information and is evaluated against the same social objective, and if H/P returns are separable, decentralization of the component choices alone does not create a welfare wedge. Every attempted wedge therefore reveals which missing primitive would be doing the real economic work.

This is the central Stage 3R negative result and the reason no candidate proceeds to formalization.
