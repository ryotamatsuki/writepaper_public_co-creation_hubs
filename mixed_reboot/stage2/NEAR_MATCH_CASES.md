# Near-Match Cases

## Purpose
Stage 2R pre-registered cross-principal near-matches `z_i ≈ z_j, R_i != R_j`. The project does **not** force these pairs from incomplete regional-state numbers.

## Result
**UNRESOLVED FOR CROSS-PRINCIPAL NUMERIC MATCHING.**

The current committed regional-state panel establishes source feasibility and channel-specific local/external linkage constructs, but does not yet contain harmonised numeric pre-decision `z` for every historical decision episode. Selecting cross-principal pairs now would therefore be researcher discretion rather than a reproducible distance rule.

## High-value substitutes that are valid now
Within-principal/menu comparisons hold regional state and sponsor identity much more tightly than a coarse cross-principal match:

- **Saga Prefecture, 2024:** Startup Connect = H; Connect+ = P; Promote = 0.
- **Okayama City:** MomoSta / local-exchange commission = H; global-network commission = P; incorporation grant = 0.
- **Tokyo Metropolitan Government:** NEXs = P; TIB = HP; deep-tech subsidy = 0.
- **Osaka City:** OIH integrated portfolio = HP; GLOBAL BRIDGE = P-specific module.
- **Akita Prefecture:** AKISTA = H; outside-startup demonstration support = P.

These comparisons support SF2/SF3 but do not identify causal effects of task scope.

## Stage 3 implication
No mechanism may rely on a claimed cross-principal `z` match from Stage 2R. A future empirical extension can populate historical numeric regional states and implement an explicit distance metric.
