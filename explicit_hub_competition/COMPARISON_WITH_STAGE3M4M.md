# Comparison with Existing Stage 3M–4M

## What the previous model did contain

PR #17 contained:

- two regional governments choosing binary hub provision;
- productive matching opportunities;
- overlap and cross-hub referral;
- capability improvement after matching;
- downstream Cournot competition;
- regional welfare and public fixed cost.

It therefore contained policy-level strategic interaction.

## What it did not contain

Conditional on a hub profile, beneficiary firms/projects never chose which intermediary would mediate a collaboration. Hub 2 could change the focal firm's match probability, but could not literally win an overlapping project away from Hub 1.

Thus `overlap` represented diminished incremental value of the second hub, not endogenous intermediation-demand allocation.

## Missing strategic margin

**ENDOGENOUS HUB CHOICE / PROJECT ALLOCATION.**

The new Stage 3M-R architecture adds only this margin and the incidence bookkeeping required to make project allocation economically meaningful.

## Status of old results

- referral-free strict substitution: retain as diagnostic;
- referral-induced complementarity: retain as diagnostic;
- downstream rivalry raises referral threshold: retain as diagnostic;
- public decentralization wedge: retain as diagnostic.

None is automatically transferred as a theorem to the explicit-competition architecture.

## Classification

Existing Stage 3M–4M: **USEFUL DIAGNOSTIC — NOT CANONICAL**.
