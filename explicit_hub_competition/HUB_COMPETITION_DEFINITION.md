# Canonical Hub Competition Definition

> **Hub competition is the endogenous allocation of overlapping productive-collaboration projects between simultaneously available public matching intermediaries, where projects choose the intermediary offering the higher expected productive match value from its partner pool.**

This definition is intentionally narrower than generic policy competition.

- Government competition concerns `E_i` responding to `E_j`.
- Hub competition concerns project/user allocation conditional on the available hubs.
- Downstream competition concerns beneficiary firms after matching.

Literal business/project stealing occurs only when both hubs are feasible for the same project and one hub's availability changes which intermediary/partner ecosystem mediates the collaboration.
