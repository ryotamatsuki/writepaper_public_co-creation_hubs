# Information Structure

Selected structure: **R2**.

Timing:

1. Governments choose binary provision.
2. Each beneficiary project observes its type `theta` and both open hubs' partner-pool composition.
3. Partner-specific compatibility is not yet known.
4. The project chooses the first hub.
5. The first hub tests compatibility in its resident pool and selects the highest productive compatible partner.
6. If no direct compatible match exists, the project may be referred to the rival hub's non-overlapping specialist.
7. A successful match determines productivity gain and partner-region incidence.
8. Beneficiary firms compete downstream.

Compatibility uncertainty is the minimum uncertainty required to make intermediation informative. No private signal, asymmetric belief, search-cost shock or taste shock is introduced.
