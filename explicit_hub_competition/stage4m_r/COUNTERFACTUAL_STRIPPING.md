# Counterfactual Stripping

## CF1 — referral = 0

`Gamma_0<0` globally. Literal project competition is strategic substitution.

## CF2 — partner-side surplus = 0

Set `sigma=0`. The exact global proof still gives `Gamma<0`. Endogenous project allocation remains payoff-relevant through beneficiary productivity and downstream profit. Partner incidence is not needed to manufacture competition.

## CF3 — downstream strategic competition = off

Use linear beneficiary value `x`. Then

`Gamma_NS=(1+sigma)(mu_B-2mu_S)`

`=-(1+sigma)p[(1-p)l+p(2-p)m] < 0`.

Without referral,

`Gamma_NS0=-(1+sigma)p[(1-p)l+m]<0`.

Referral raises `Gamma_NS` by `(1+sigma)mp(1-p)^2`, i.e. weakens substitution, but never reaches zero.

## CF4 — endogenous choice -> random first hub

With a 50-50 random first hub,

`mu_R = p(1+(1-p)^2)(h+m)/2 + p(1-p)l`.

Endogenous choice raises expected productivity by

`mu_B-mu_R = p^2(2-p)(h-m)/2 > 0`.

Thus allocation is not cosmetic. Numerical hard kill finds random allocation also globally/substantively substitute; endogenous choice changes levels and the magnitude of `Gamma`, not the sign.

## CF5 — decentralized governments -> planner

The planner wedge survives; `X_0>0`, while `X_1` can have either sign. Nevertheless `G_1-G_0=2Gamma<0`.
