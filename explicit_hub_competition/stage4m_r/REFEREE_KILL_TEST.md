# Referee Kill Test

## Ten mandatory questions

1. **Referral removed:** yes, hub provision is globally strategic substitutes.
2. **Can referral offset project stealing?** It offsets part of it but cannot reverse the sign; `Gamma<0` globally.
3. **Both signs on open sets?** No. There is no admissible open set with `Gamma>0`.
4. **Does explicit allocation change PR #17?** Yes, qualitatively: PR #17's referral-induced complementarity disappears.
5. **Role of downstream rivalry:** quantitative shift only for the final sign. `Gamma` is negative with and without Cournot.
6. **Planner wedge:** yes. The first-hub externality is positive; the second-hub externality is sign-ambiguous.
7. **Competing-matchmaker absorption:** generic endogenous sorting is already absorbed by Damiano-Li/Caillaud-Jullien; public user competition is threatened by Takahashi/Walz. No exact single-paper one-page isomorphism was established, but the surviving theorem is too weak to carry novelty.
8. **Set partner surplus to zero:** allocation remains payoff-relevant; `Gamma<0`. Partner surplus is not an artificial attraction rent.
9. **No referral:** what remains is mostly project stealing/overlap and a global substitution result; this is not a sufficient standalone contribution.
10. **No downstream rivalry:** endogenous project choice, referral, regional incidence and a planner wedge survive, but strategic interaction remains substitution.

## Hard decision

The architecture passes the consistency gate but fails the central theorem gate. A sign reversal would require a prohibited extra feature such as capacity, pricing, network effects, quality investment or another strategic margin.
