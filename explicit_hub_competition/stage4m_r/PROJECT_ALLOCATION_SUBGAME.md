# Project Allocation Subgame

With both hubs open, a type-1 project strictly chooses Hub 1 and a type-2 project strictly chooses Hub 2.

Let `q=1-p`. Type 1 obtains the productivity distribution

Preferred-first: `{h:p, l:qp, m:q^2p, 0:q^3}`.

Rival-first: `{m:p, l:qp, h:q^2p, 0:q^3}`.

Preferred-first moves probability `p(1-q^2)=p^2(2-p)>0` from `m` to `h`. It therefore first-order stochastically dominates rival-first.

When only one hub is open, both project types use that hub. When the second hub opens, projects whose high-fit specialist is located there switch to it. This is literal endogenous project stealing, not an imposed market-share term.

If both types are equiprobable, each open hub mediates one half of projects in expectation when both are available.
