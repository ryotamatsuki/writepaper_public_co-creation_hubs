# Competitive Object Selection

## Candidates

### C1 — Firm/User Competition

Strong institutional fit and literal hub competition, but too coarse because the economic object being intermediated is a collaboration project rather than the firm as a whole. It also risks implying that a firm must commit all activity to one hub.

### C2 — Project Allocation Competition

Very strong fit. It directly captures hubs contesting productive collaboration opportunities and allows the same firm to use different intermediaries for different needs. However, standing alone it obscures how project outcomes map into the downstream beneficiary firm.

### C3 — Partner Competition

Institutionally plausible for universities, experts and investors, but introduces a second endogenous choice side and moves the baseline toward a two-sided-platform model. This is unnecessary for the first explicit-competition hard kill.

### C4 — Joint Firm–Project Representation

**SELECTED.** Each project is attached to a beneficiary firm, and that firm chooses an intermediary for the project. This keeps downstream incidence explicit without creating a second platform-demand side.

## Why C4 is minimal

C4 retains the economic content of C2 while avoiding an extra population. It allows:

- literal project stealing between hubs;
- region-specific downstream firms;
- foreign-hub use without firm relocation;
- partner-side regional incidence;
- subsequent product-market competition.

## Canonical competitive object

**Hubs compete to mediate productive collaboration projects belonging to region-specific beneficiary firms.**
