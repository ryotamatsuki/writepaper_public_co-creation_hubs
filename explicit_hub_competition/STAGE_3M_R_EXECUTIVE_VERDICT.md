# Stage 3M-R Executive Verdict

## Canonical verdict

**PASS — EXPLICIT HUB COMPETITION HAS A COHERENT MINIMAL MATCHING ARCHITECTURE.**

Reason code: **C4–D1–A1–I3**.

- Competitive object: joint beneficiary-firm/project representation (C4).
- Hub differentiation: partner-set differentiation (D1).
- Endogenous allocation: expected productive-match value (A1).
- Regional incidence: both beneficiary-firm home region and complementary-partner region receive economically grounded parts of collaboration value (I3).

## Core architecture

A region-specific beneficiary firm has a collaboration project and may use either open public hub. Hub `i` searches a region-anchored complementary partner pool `S_i`. Heterogeneous projects differ in needed capability and potential fit with partners. When both hubs can serve a project, the project chooses the hub with the higher expected productive-match value generated by its partner pool. If the first hub cannot complete a productive match, cross-hub referral may expose the project to the rival hub's non-overlapping partner pool.

Competition and cooperation therefore come from the same partner-set environment:

- overlap / common feasible capabilities -> project competition;
- non-overlapping capabilities + referral -> cooperation / expanded feasible match set.

## Critical public-incidence result at the architecture level

Project allocation is not cosmetic because a productive collaboration has two regionally located sides. The beneficiary firm's capability/profit gain remains with the firm's home region, while the complementary partner's collaboration surplus accrues to the partner's region. The host government pays hub cost but receives no private intermediary fee.

This gives decentralized governments a reason to care about which hub/partner ecosystem mediates a project without assuming arbitrary hub revenue or relocation of the beneficiary firm.

## Prior-art status

**HIGH ABSORPTION RISK, NOT ABSORBED AT THE ARCHITECTURE STAGE.**

Competing-matchmaker theory already absorbs endogenous intermediary choice and heterogeneous matching. Regional public-input/location theory already absorbs governments competing for mobile firms. The surviving structural distinction to hard-kill in Stage 4M-R is split regional incidence of a collaboration link without beneficiary-firm relocation, together with partner-set overlap/referral and downstream rivalry.

No novelty claim is made.
