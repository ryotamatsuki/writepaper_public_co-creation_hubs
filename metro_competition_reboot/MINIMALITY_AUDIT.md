# Minimality Audit

| Object | Status | Reason |
|---|---|---|
| `x_1,x_2` | **ESSENTIAL** | continuous local strategic conduct and policy lever |
| `p_T` | **ESSENTIAL** | strategic metropolitan response/access threshold |
| project type `theta` | **ESSENTIAL** | productive-fit heterogeneity |
| partner-pool differentiation | **ESSENTIAL** | prevents taste-based hub differentiation |
| overlap | **ESSENTIAL, DERIVED** | needed for nontrivial two-local-hub duplication mechanism; must come from sets/distributions |
| no-hub option `0` | **ESSENTIAL** | creates genuine uncovered-project margin |
| private hub `H_T` | **ESSENTIAL** | central outside competitor in RQ |
| variable investment cost `C_i(x_i)` | **ESSENTIAL** | defines optimal investment rather than monotone maxing-out |
| partner-side surplus | **USEFUL EXTENSION** | regional incidence/welfare; not required for productive additionality |
| fixed cost `F` | **USEFUL EXTENSION** | needed only for binary existence/provision threshold |
| diagnosis | **USEFUL EXTENSION / embedded microfoundation** | may implement `x_i`; must not be separate utility term |
| referral | **USEFUL EXTENSION** | not baseline; prior art and PR #21 make it a risky rescue |
| downstream competition | **USEFUL EXTENSION** | not needed to test matching additionality |
| endogenous `x_T` | **REDUNDANT BASELINE** | adds complexity and mixed-platform prior-art exposure |
| Hotelling/logit taste | **PROHIBITED RESCUE** | violates productive-fit primitive |
| arbitrary `-gamma x_i x_j` | **PROHIBITED RESCUE** | competition must derive from partner overlap |
| automatic failure-only referral | **PROHIBITED RESCUE BASELINE** | PR #21 diagnostic architecture should not be reimported |
| independent universal compatibility `p` | **REDUNDANT/PROHIBITED AS DEFAULT** | would erase the overlap/correlation object that now carries the candidate contribution |

The minimum baseline therefore contains only `theta`, partner opportunity sets, `x_1,x_2`, `p_T`, project choice including `0`, and real investment costs.
