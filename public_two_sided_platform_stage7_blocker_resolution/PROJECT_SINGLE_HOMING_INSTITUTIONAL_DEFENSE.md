# Project Single-Homing Institutional Defense

## Verdict

**PLAUSIBLE AS A FOCAL-PROJECT PRIMARY-ROUTE ABSTRACTION; NOT ESTABLISHED AS FIRM-LEVEL EXCLUSIVITY.**

Real firms can hold memberships, attend events or interact with several innovation ecosystems simultaneously. The paper must not claim otherwise.

The frozen choice `0,H_1,H_2,H_T` is instead interpreted at the level of a focal collaboration project: for the modeled search/matching episode, the project selects one **primary intermediation route** through which it forms or advances the focal match. Other background memberships or ecosystem contacts are outside that choice.

This abstraction is institutionally defensible because the services under study—curated matching, mentoring, project formation, programme participation and community access—can be treated as alternative primary routes for one focal project even when the parent firm is not exclusive.

## Referee discipline

A referee can correctly object that actual projects sometimes combine routes. That objection **SURVIVES BUT IS NONFATAL** for a minimal theory model so long as the paper:

1. labels single-homing as an abstraction;
2. never asserts contractual exclusivity;
3. does not use firm-level registration counts as proof of single-homing;
4. treats project multi-homing as a future extension rather than silently adding it now.
