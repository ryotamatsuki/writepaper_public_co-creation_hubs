# Frozen Model Institutional Mapping

This document maps the already-frozen objects to an institutional class. It changes no primitive.

| Frozen object | Canonical institutional interpretation after blocker resolution |
|---|---|
| `G_i` | regional/local government financing or governing public innovation intermediation |
| `H_i` | regional public innovation hub/intermediary |
| `x_i` | facilitation capacity: coordinators, matching, events, partner recruitment, programme quality |
| `H_T` | shared metropolitan private innovation hub accessible from both regions |
| `p_T` | effective paid membership/access price for the private hub's workspace-plus-intermediation bundle |
| `n_h^F` | focal innovation projects using hub `h` as their primary intermediation route |
| `n_h^P` | partners, experts, investors, corporates and supporting organisations connected to hub `h` |
| project single-homing | one focal project chooses one primary route in the modeled decision |
| partner multi-homing | support-side actors may connect to more than one ecosystem |

The interpretation deliberately does not add distance costs, travel costs, metropolitan-specific project types, another platform, contracting, or multi-homing on the project side.

## Direct analogues

- Public `H_i,x_i`: E:N BASE-type regional facilitation; internationally, Helsinki Campus Incubators and Barcelona Activa Startup Lab.
- Private `H_T,p_T`: primarily CIC Tokyo; secondary Japanese analogues QWS and SENQ; overseas Level39 and CIC campuses.

## Limits

`p_T` is a reduced-form effective access price. In observed hubs it commonly bundles physical workspace with community/network/intermediation access. The model does not claim a separately invoiced pure matching fee.

The model also does not claim that every innovation hub fits this architecture. Free hubs (e.g. current QUINTBRIDGE), public/nonprofit operators, or institutions without a discretionary paid member side are boundary/counterexamples.
