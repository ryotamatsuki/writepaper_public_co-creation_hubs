# Stage 6 — Theoretical Distance Matrix

The classification asks whether each change required to obtain the hardened Proposition 2 is merely notation/specialization or introduces a new economic interaction.

## 1. Peitz & Sato (2026)

| Required change | Classification | Assessment |
|---|---|---|
| symmetric free-entry fringe -> two named binary entrants | TECHNICAL + ECONOMICALLY SUBSTANTIVE | changes zero-profit entrant-count problem into a bilateral entry game |
| define `Gamma_i = payoff_i(E_j=1)-payoff_i(E_j=0)` | ECONOMICALLY SUBSTANTIVE ANALYTICAL OBJECT | not present in their free-entry equilibrium |
| introduce a distinct residual incumbent option used by both entrant populations | ECONOMICALLY SUBSTANTIVE NEW INTERACTION | central candidate mechanism |
| make residual incumbent value depend on the mass left after both entrants draw users away | ECONOMICALLY SUBSTANTIVE NEW INTERACTION | creates cross-entry outside-option feedback |
| separate core-side from entrant-side feedback | ECONOMICALLY SUBSTANTIVE | not their within/cross-user-group comparison |
| prove entrant-side-only negativity/core-side open-set crossing | NEW THEOREM | not a short corollary |

**<1 page derivation? NO.**

## Bottom line

No top-five paper requires only notation changes or parameter specialization to generate the hardened Proposition 2. The strongest threat is not exact absorption but **contribution-size risk**: a referee may view the residual-core construction as a narrow new application of familiar network/business-stealing forces. That evaluative issue should be confronted in Stage 7 and later hostile-referee gates without adding model features.
