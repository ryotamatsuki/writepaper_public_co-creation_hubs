## Citation chaining

### Peitz–Sato cluster

Peitz–Sato -> Tan–Zhou / Armstrong / classic platform competition -> current asymmetric/network-entry papers. The published full-text free-entry definition and Proposition 7/8 were re-opened after the hardening result.

### Network-architecture cluster

Amir–Evstigneev–Gama -> Amir–Lazzati single-network predecessor -> Gama firm-specific entry, Gama–Samano compatible free entry, and related compatibility/free-entry descendants. This chaining produced the strongest new kill: broad `network location/architecture changes entry` novelty is not available.

### Outside-option/common-enemy cluster

De Jaegher review -> formal criticality/common-enemy models and network disruption; independent search identified Morales–Rodero-Cosano on market entry with an endogenous outside option. These sources kill broad common-rival/endogenous-outside-option language but not the residual-network bilateral diagnostic.

No exact paper or immediate specialization was identified for the narrow proposition:

`two named entrants -> diversion from a third residual network -> lower common outside-option value -> bilateral cross-entry sign reversal`, together with `core-only feedback sufficient / entrant-only feedback insufficient in the canonical class`.

However, several broader claims are prior art and are explicitly removed from the contribution set. See `NETWORK_LOCATION_PRIOR_ART.md` and `STAGE_06_POST_HARDENING_NOVELTY_REKILL.md`.
