## Core matrix conclusion

No inspected paper simultaneously contains the four elements necessary for a short derivation of Proposition 2:

1. two named peripheral entry decisions;
2. a distinct residual incumbent option used by both peripheral populations;
3. incumbent/core value that changes with the residual user mass left after both entry decisions;
4. a diagnostic comparison that shuts down core-side versus entrant-side network feedback and signs the bilateral cross-entry effect.

The closest papers contain important subsets, which is why the contribution statement is narrowed sharply. In particular, Amir–Evstigneev–Gama kills the broad `network architecture/location changes entry` claim, while Peitz–Sato and Tan–Zhou kill the broad `network effects can reverse entry effects` claim.
