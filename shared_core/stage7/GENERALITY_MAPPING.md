# Stage 7 — Generality Mapping

The exact abstract structure requires six elements:

1. two peripheral entrants;
2. a distinct shared residual core/incumbent;
3. agents choose among peripheral and core options;
4. peripheral entry diverts users from the core;
5. core value falls when its installed base becomes thinner;
6. both peripheral entrants face that same endogenous outside option.

A mapping fails if it obtains generality only by changing these elements.

## Summary assessment

| Environment | Mapping quality | Main reason |
|---|---|---|
| Regional public co-creation / innovation hubs | WEAK FIT | common Tokyo/national ecosystem and network value are plausible, but direct diversion from the core is not established; official Ehime design emphasizes complementarity and linkage |
| Local entrepreneurship/business-support hubs | WEAK / PLAUSIBLE | overlapping support functions can substitute at the margin, but institutional designs typically connect local firms to metropolitan resources rather than displace them |
| Local labor-market/job-matching intermediaries around a dominant national platform | PLAUSIBLE BUT NOT EXACT | multiple search channels and platform/public-agency substitution exist, but multi-channel use is common and the one-sided core installed-base formulation is only a reduced form |
| Local marketplaces/service intermediaries around a dominant network platform | STRONG PLAUSIBLE / NEAR-EXACT | users can choose between local and dominant options; local entry can reduce the dominant installed base and hence its network value; however this remains within the platform family already covered by Stage 6 prior art |
| Local research/technology-transfer intermediaries around a national ecosystem | WEAK FIT | intermediation is real, but evidence more naturally supports complementarity/pipelines than depletion of a common residual core |
| Peripheral shopping malls versus a common downtown retail agglomeration | STRONG PLAUSIBLE | shoppers reallocate between peripheral malls and downtown; downtown attractiveness rises with variety/footfall; mall growth can hollow out the center; distance provides a natural \(\tau\) |
| Regional airports versus a dominant hub airport | STRONG PLAUSIBLE | passengers choose regional versus hub routing; hub value comes from network connectivity and traffic concentration; hub bypass/diversion reduces hub traffic/connectivity; regional access costs provide \(\tau\) |

## A. Regional innovation / co-creation hubs

### Literal mapping

| Canonical object | Application object |
|---|---|
| core \(M\) | Tokyo/metropolitan or national startup/innovation ecosystem such as NEXs Tokyo / the Tokyo startup ecosystem |
| \(A_M\) | metropolitan-specific access to investors, corporations, mentors, markets and information |
| \(n_M\) | active firms/startups/partners participating in the central ecosystem |
| \(\beta\) | value generated by participant diversity, matching opportunities and human-network thickness |
| entrant 1 | a regional hub such as E:N BASE |
| entrant 2 | another regional hub such as Setouchi-i-Base |
| \(A_L\) | local support, proximity, administrative access and local community value |
| \(c\) | heterogeneous participation/travel/relationship cost |
| \(\tau\) | extra cost of using another region's hub |
| \(F\) | fixed institutional/facility commitment to establish a regional hub |

### Critical test

The official evidence strongly supports a shared Tokyo/national network and central matching resources. However, the critical diversion step is weak. Ehime's official 2026 metropolitan co-creation project explicitly aims to strengthen networks between E:N BASE members and metropolitan companies and create mutual collaboration. Earlier Ehime policy also treated digital, metropolitan and local co-creation hubs as a portfolio to be jointly utilized.

**Classification: WEAK FIT.** The model is not currently justified as a literal empirical description of co-creation-hub interaction. It may remain a motivating analogy only if the paper clearly labels core diversion as a theoretical possibility rather than an established institutional fact.

## B. Local entrepreneurship/business-support hubs

The structure is similar to the co-creation-hub case: local centers provide mentoring, matching, events and workspace while metropolitan/national ecosystems provide broader investor and partner access. The same services overlap enough for partial substitution in scarce founder time, but policy programmes often deliberately connect local and national ecosystems.

**Classification: WEAK / PLAUSIBLE.** No new theoretical structure is required, but the key residual-core depletion channel needs case-specific evidence.

## C. Labor-market/job-matching intermediaries

Workers and firms use job postings, personal networks and public employment agencies. Carrillo-Tudela, Kaas and Lochner document distinct search channels, and public/private matching platforms in Japan have measurable user and vacancy elasticities. A local employment intermediary can draw search activity away from a national digital platform, reducing its matching thickness.

However, empirical labor search is explicitly multi-channel, so the canonical single-homing assumption is not a literal description.

**Classification: PLAUSIBLE BUT NOT EXACT.** The mechanism is a defensible reduced form for an exclusive search episode, but not a literal model of total job search.

## D. Local marketplaces around a dominant network platform

This is the closest structural mapping. Users choose among a common dominant platform and local alternatives; local entry can divert users from the dominant installed base; the dominant platform's value is network-dependent; both local entrants share the same outside option.

**Classification: STRONG PLAUSIBLE / NEAR-EXACT.** This establishes generality of the mechanism but remains close to the platform-entry literature, so it should not be used to inflate novelty claims.

## E. Research/technology-transfer intermediaries

Local TLOs, public innovation intermediaries and national/metropolitan ecosystems all intermediate search and knowledge transfer. But existing evidence more naturally describes local intermediaries as connecting firms to extra-regional knowledge rather than eroding the value of a residual national core.

**Classification: WEAK FIT.** It does not independently validate the theorem's central depletion channel.

## F. Peripheral shopping malls versus a downtown retail agglomeration

This provides a strong non-platform mapping.

| Canonical object | Retail object |
|---|---|
| core \(M\) | common downtown shopping district |
| \(A_M\) | intrinsic central-city accessibility/amenity value |
| \(n_M\) | downtown patronage / retail activity |
| \(\beta\) | shopping/agglomeration externality through variety and footfall |
| entrants 1,2 | peripheral shopping centers/malls serving different peripheral areas |
| \(A_L\) | local mall convenience and amenities |
| \(c\) | consumer-specific travel/taste cost |
| \(\tau\) | extra distance to the other peripheral mall |
| \(F\) | fixed mall-development cost |

Ushchev, Sloev and Thisse show that consumers choose downtown and/or an outlying mall, that marketplace size creates a network effect through variety, and that a sufficiently large mall can eliminate downtown retailers. Retail-agglomeration evidence also links local footfall to productivity and documents the decline of shopping streets under competition from planned malls.

The canonical single-homing model is a simplification because shoppers can visit multiple centers across occasions, but per shopping occasion the structure is close.

**Classification: STRONG PLAUSIBLE.** This is an economically distinct environment and supports Stage-7 generality without adding a theoretical primitive.

## G. Regional airports versus a dominant hub airport

This is another strong non-platform mapping.

| Canonical object | Air-transport object |
|---|---|
| core \(M\) | dominant hub airport |
| \(A_M\) | intrinsic location/service quality |
| \(n_M\) | hub passenger/flight traffic |
| \(\beta\) | network value from connectivity, frequency and connection opportunities |
| entrants 1,2 | regional airports or regional gateway services |
| \(A_L\) | local access convenience |
| \(c\) | traveler-specific generalized access cost |
| \(\tau\) | extra access cost to the other regional airport |
| \(F\) | fixed airport/gateway establishment cost |

Mayer and Sinai document network benefits from hubbing: clustered flights generate many connection opportunities. The airport literature also studies hub bypass and traffic redistribution to regional airports; dehubbing reduces connectivity and hub bypass can allow regional airports to develop new markets.

The reduced form abstracts from airlines as an intermediate decision maker, so it is not exact.

**Classification: STRONG PLAUSIBLE.** It shows the mechanism is not merely a relabeled public-platform result.

## Generality verdict

The theorem does **not** pass generality because of co-creation hubs. It passes because the same residual-core logic has strong plausible mappings in at least two economically distinct environments—retail agglomerations and hub airports—without changing the mathematical structure.

Accordingly, if the project proceeds, the theory should be framed as a general IO/organizational entry mechanism. The original co-creation-hub setting should not be presented as the sole or definitive institutional embodiment of the model.
