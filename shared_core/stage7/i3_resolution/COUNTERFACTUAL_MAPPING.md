# Counterfactual Mapping

## Required counterfactual

The canonical application requires that, if a regional hub did not exist, at least some marginal users would participate more directly in the shared metropolitan/national core. In the model this is the institutional counterpart of `E_j=1 -> n_M down`.

## E:N BASE-specific assessment

**UNKNOWN.**

No primary source was found that measures or states that firms using E:N BASE would otherwise use NEXs Tokyo, Tokyo Innovation Base, national startup programs, metropolitan investors, or other common-core institutions more intensively.

There is functional overlap in networking, matching, consultation and events, and generic startup-program evidence shows that participation can consume scarce managerial time. Those facts make partial substitution plausible. They do not identify the E:N BASE counterfactual.

Moreover, Ehime's explicit metropolitan program is designed to strengthen networks between E:N BASE members and metropolitan firms. This makes a pure displacement story especially unsafe.

## Broader startup-support counterfactual

**PARTIALLY PLAUSIBLE.**

JETRO explicitly records cases in which participation across multiple accelerator programs dispersed startups' valuable time/resources; some accelerators prohibit concurrent participation; others require very large executive time commitments. Aarstad et al. (2016) finds substitution between regional and international innovation collaboration for medium-sized firms.

Thus a general limited-participation-capacity channel is real enough to be institutionally defensible. What is missing is evidence that the Ehime-type regional hub is the activity that displaces participation in one particular common metropolitan core.

## Model-application distance matrix

| Model object | Institutional counterpart | Match |
|---|---|---|
| common core | Tokyo/national innovation ecosystem, with NEXs Tokyo as one concrete node | **STRONG** |
| network-dependent core value | value from dense corporate, investor, mentor and peer network | **STRONG** |
| two peripheral hubs | separate prefectural/local co-creation ecosystems | **MEDIUM** |
| overlapping user population | regional startups/firms can access both local and Tokyo/national support | **MEDIUM-STRONG** |
| entrant diverts participation | local participation reduces direct core participation/attention | **WEAK / UNOBSERVED** |
| common core shared by both regions | NEXs/national networks accessible from multiple regions | **STRONG** |
| cross-regional friction `tau` | geography, local embeddedness, eligibility and relationship costs | **MEDIUM** |
| fixed establishment cost | discrete public investment/operating commitment to open a hub | **STRONG** |
| single-homing approximation | firms often multi-home across programs and ecosystems | **WEAK** |

## Conclusion

The decisive distance is not the existence of local and central networks. It is the unobserved marginal displacement between them. That distance is large enough to prevent co-creation hubs from remaining the headline institutional validation of the frozen theorem.
