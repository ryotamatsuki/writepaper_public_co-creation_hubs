# Functional Overlap Matrix

Comparison object: E:N BASE / analogous regional hubs versus NEXs Tokyo / metropolitan-national startup ecosystem.

| Function | Regional hub evidence | Shared-core evidence | Overlap |
|---|---|---|---|
| mentor / accompaniment access | E:N BASE consultation/accompaniment and recurring expert events | NEXs acceleration programs, concierges, partner network | **YES / PARTIAL** |
| investor access | not a defining E:N BASE function in the audited primary material | NEXs / Tokyo ecosystem includes investors and support partners | **PARTIAL** |
| corporate matching | municipality pitches, open-innovation opportunity creation, networking | matching concierge, partner needs database, collaborative programs | **YES** |
| peer networking | recurring meetups and member community | nationwide startup/partner community and events | **YES** |
| event participation | recurring seminars, workshops, meetups | frequent networking, seminars and NEXs Fes | **YES** |
| business consultation | consultation/accompaniment support | community managers / matching and acceleration support | **YES / PARTIAL** |
| innovation partner search | explicit co-creation and matching objective | explicit matching and collaborative-project creation | **YES** |
| university linkage | possible through broad partner/community architecture but not central in audited evidence | universities/support organizations can participate in wider ecosystem | **PARTIAL** |
| recruitment | not established as core E:N BASE function | some ecosystem employment/recruitment content, but not central to I3 | **LOW** |
| funding information / fundraising | indirect / event dependent | metropolitan ecosystem and acceleration programs provide stronger capital/investor access | **PARTIAL** |

## Interpretation

Material overlap exists in networking, matching, event participation, consultation and partner search. Therefore, substitution is not impossible on functional grounds.

However, overlap alone does not establish diversion. In Ehime's actual institutional design, local activities are deliberately connected to metropolitan partners. The functional-overlap test therefore passes only the first step of I3; it does not establish the required counterfactual that local use reduces direct core use.
