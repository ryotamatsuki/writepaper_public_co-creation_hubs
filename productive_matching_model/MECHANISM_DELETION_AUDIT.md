# Mechanism Deletion Audit

| Mechanism removed | Result | Classification |
|---|---|---|
| overlap | M0 cross-effect collapses to zero in the corresponding independent-pool benchmark; strict substitution disappears | ESSENTIAL TO BASELINE SUBSTITUTION |
| referral/shared pool | `Gamma=Gamma_0<0` globally | ESSENTIAL TO COMPLEMENTARITY |
| downstream strategic competition | sign reversal survives with `Gamma_NS=V(k-p)` | NOT ESSENTIAL TO SIGN REVERSAL |
| decentralized regional government | strategic public-entry game disappears; a planner internalizes both regional welfare changes | ESSENTIAL TO PUBLIC-POLICY WEDGE |

## Overlap deletion

Overlap is not represented by an arbitrary negative interaction. It is the fact that either hub can reveal the same shared complementary opportunity. If the pools are fully disjoint and no cross-service exists, neighbor provision does not preempt any own matching opportunity, so the M0 strategic cross-effect vanishes.

## Referral deletion

Setting `r=0` gives `k=0` and the exact theorem `Gamma_0<0`. Hence the positive cross-hub channel is necessary for complementarity in the minimal model.

## Downstream competition deletion

Under a nonstrategic match value `V`, `Gamma_NS=V(k-p)`. Both signs remain possible, so downstream competition is not a primitive source of the duality. However, Cournot shifts the referral threshold upward: at `k=p`, `Gamma_C<0`. Therefore downstream competition creates a distinct regional-government incentive wedge.

## Decentralization deletion

A central planner chooses provision using `S_e=D_e+X_e`; decentralized governments use `D_e`. Since `X_0>0` globally and `X_1` can differ in sign/magnitude, decentralization changes provision incentives.

## Bottom line

The minimal duality has two matching-side primitives only:

1. duplicated/overlapping opportunity access (negative cross effect);
2. bilateral referral/shared-pool access (positive cross effect).

Downstream competition and decentralized public objectives do not create the basic sign reversal, but they convert it into a regional industrial-policy problem with a distinct threshold and welfare wedge.
