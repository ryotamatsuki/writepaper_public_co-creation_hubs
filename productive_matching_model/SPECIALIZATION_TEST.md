# One-Page Specialization Test

## Caillaud & Jullien (2003)

| Our object | Closest prior-art object |
|---|---|
| binary public hub provision `E_i` | private intermediary operation/pricing strategy |
| productive matching probability | successful intermediation / cross-side participation |
| complementary capability fit | not the central match-value primitive |
| overlapping opportunity | nonexclusive use/multihoming is related but not identical |
| bilateral referral pool | indirect network externality / cross-side participation, not a public referral technology |
| beneficiary regional firm | platform user |
| downstream Cournot competition | absent |
| regional welfare | private intermediary profit / user surplus architecture |
| `Gamma^M` public cross-entry effect | no direct counterpart |

**Verdict: NOT ABSORBED.** A relabeling is insufficient; one must add a public binary provision layer, productive-capability mapping, downstream oligopoly, and regional welfare. Those additions create the exact threshold-wedge proposition.

## Referee objection

> This is just Caillaud–Jullien competing matchmakers with public ownership and downstream Cournot appended.

## Stage 4 response

The matching-side cooperation/substitution duality by itself is not claimed as novel. The minimal model yields an additional exact result: in the nonstrategic matching benchmark the complementarity threshold is `k=p`, whereas with homogeneous Cournot and regional welfare the cross-effect at `k=p` is

`-7 Delta^2 p^2(p^2-4p+5)/18 < 0`.

Hence downstream strategic competition strictly raises the referral strength needed to turn public hubs into complements. Public decentralization further creates an externality wedge because each government ignores the neighboring region's welfare change. Neither proposition is a direct relabeling of the price/multihoming results identified in Caillaud–Jullien.

This is sufficient for a Stage 4 GO but not for a novelty claim. Stage 6M must search these exact propositions.
