# Matching-Only Baseline M0

Set referral probability `r=0`, hence `k=0` and `t=h=2p-p^2`.

The regional-welfare cross-entry effect is

`Gamma_0 = -Delta p[8A+Delta(11-14p^2+7p^3)]/18`.

For `p in (0,1)`, define

`g(p)=11-14p^2+7p^3`.

Then

`g'(p)=7p(3p-4)<0` on `(0,1)`, and `g(1)=4`.

Therefore `g(p)>4>0`. Under `A>Delta>0`, every term in the bracket is strictly positive, so

`Gamma_0<0`.

## Proposition M0

**Without cross-hub referral/shared-pool access, overlapping public productive-matching hubs are strict strategic substitutes throughout the admissible interior domain.**

The result is not driven by the hub fixed cost `F`, which cancels from `Gamma`.

## Economic interpretation

When referral is absent, the neighbor hub already exposes the focal region to the overlapping partner opportunity. Opening the focal hub after the neighbor is present therefore has lower incremental matching value than opening it from `00`. Downstream rivalry does not reverse that duplication effect in the canonical regional-welfare objective.

## Deletion note

If overlap itself is deleted, the M0 cross-entry effect collapses to zero in the corresponding independent-pool benchmark. Thus strict substitution here is generated by duplicated matching opportunities rather than an arbitrary negative interaction term.
