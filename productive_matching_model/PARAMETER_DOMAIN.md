# Parameter Domain and Limiting Cases

## Canonical admissible domain

`A>Delta>0`,

`0<p<1`,

`0<=r<=1`,

`F>0`.

The condition `A>Delta` guarantees positive Cournot quantities even in the worst asymmetric match state `(m_i,m_j)=(0,1)` because `q_i=(A-Delta)/3>0`.

Define

`h=2p-p^2`,

`k=(1-p)^2 r`,

`t=h+k`.

Then `0<p<h<1`, `0<=k<=(1-p)^2`, and `h<=t<=1`.

## Limiting cases

### Zero referral

`r=0 => k=0`.

M0 obtains and `Gamma<0` globally.

### Maximal referral

`r=1 => t=1`.

The maximal cross-effect is

`Gamma_max = Delta[8A(1-3p+p^2)+Delta(4-33p+39p^2-14p^3)]/18`.

A complementarity region exists iff this value is positive.

### Vanishing overlap probability

As `p->0`, the duplication force vanishes. A positive referral opportunity then dominates for any fixed interior `r>0`, so complementarity becomes easy to sustain.

### Very strong overlap

As `p->1`, `k=(1-p)^2r->0`: there is almost no distinct referral opportunity left after the highly productive overlapping/home opportunities are exhausted. The model therefore converges to substitution.

### No capability gain

As `Delta->0`, all matching consequences for market outcomes vanish and gross hub benefits converge to zero. There is no meaningful provision incentive absent a productive consequence of collaboration.

### Zero hub cost

`F=0` affects equilibrium selection/provision levels but not `Gamma`, because `F` cancels from the cross-entry comparison.

### Very high hub cost

If `F>max{D_0,D_1}` when both thresholds are positive, no government wishes to open a hub.

### No downstream strategic interaction

Replacing Cournot with independent match value `V` yields `Gamma_NS=V(k-p)`. This preserves the matching-side duality but removes the product-market government wedge.

## Parameter minimality

- `p`: necessary to represent compatibility plus overlap/home discovery in one normalized primitive;
- `r`: necessary and uniquely assigned to bilateral referral/shared-pool access;
- `Delta`: necessary to map productive matching into economic capability;
- `A`: necessary for a nondegenerate homogeneous Cournot market;
- `F`: necessary for endogenous public hub provision but irrelevant to the strategic cross-effect itself.

No parameter is retained solely to manufacture both signs.
