# Welfare Preview

This file records only theorem-relevant welfare wedges. It is not a final welfare contribution claim.

## First-hub externality

When region 1 opens from `00` to `10`, region 2's gross welfare change is

`X_0 = Delta p[12A+4A p+Delta(27-33p+14p^2)]/36`.

The quadratic in `p` has negative discriminant and a positive leading coefficient, so `X_0>0` on the admissible domain.

Therefore the decentralized first-hub threshold `D_0` is strictly below the planner threshold `S_0=D_0+X_0`.

This creates a clean under-provision possibility for the first hub.

## Second-hub externality

When the neighbor hub is already open, the cross-region effect of the focal hub is

`X_1 = R_j(t,t)-R_j(h,p)`.

Unlike `X_0`, this effect is not globally signed. The focal hub can raise the neighboring firm's matching opportunities through referral, but it also strengthens the focal beneficiary firm in the downstream market.

For the exact calibration `A=1`, `Delta=1/2`, `p=1/10`:

### No referral (`r=0`)

`D_0 = 1283/18000 ≈ 0.0712778`

`X_0 = 38/1125 ≈ 0.0337778`

`S_0 = 1891/18000 ≈ 0.1050556`

For the second hub:

`D_1 = 2717/80000 ≈ 0.0339625`

`X_1 = -283/80000 ≈ -0.0035375`

`S_1 = 1217/40000 ≈ 0.030425`.

Here the decentralized government values the second hub more than the planner at the margin, creating an over-provision interval for fixed cost `F` between `S_1` and `D_1`.

### Referral (`r=1/10`)

The same `A,Delta,p` give

`D_1 = 485657/8000000 ≈ 0.0607071`,

`X_1 = 185657/8000000 ≈ 0.0232071`,

`S_1 = 335657/4000000 ≈ 0.0839143`.

Here the second hub creates a positive externality and under-provision becomes possible.

## Welfare conclusion

The model supports both signs of the second-hub decentralization wedge without adding a separate welfare externality. The sign is generated by the same matching/referral and downstream-competition architecture. This is a preview only; Stage 6M must determine whether any welfare result is proposition-level novel.
