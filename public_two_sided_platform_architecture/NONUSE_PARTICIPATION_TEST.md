# Non-Use Participation Test

For resident region r and platform h, selected project utility is

`U_rh(z)=z[v+alpha n_h^P]-kappa_rh-1{h=T}p_T`, with `U_0=0`.

Hence the platform-vs-nonuse cutoff is

`z_h0^r=(kappa_rh+1{h=T}p_T)/(v+alpha n_h^P)`.

For positive real access costs and interior network values, an open set has `0<min_h z_h0^r<1`, producing positive non-use together with active platforms.

Pairwise platform cutoffs are also interior on open parameter sets, so non-use is not supported by an artificial atom.
