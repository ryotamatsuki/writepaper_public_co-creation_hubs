# Rival Public Access Test

Every resident project can choose both public platforms.

Normalize

`kappa_rr = kappa_L`,

`kappa_rj = kappa_L + tau`, `tau >= 0`.

`tau` is a real cross-region coordination/access cost, not a taste shock. At symmetric public investments the local platform may dominate the rival for a resident project. Rival-public demand nevertheless becomes positive on an open set when the rival network advantage exceeds `tau`.

Stage 4 must not use geography as the headline mechanism and must report results at small/zero `tau` where feasible.
