# Cross-Side Effect Candidates

Selected baseline keeps two directional effects conceptually distinct:

- `alpha > 0`: partner participation raises project value;
- `beta > 0`: project participation raises partner value.

Project utility uses `v + alpha n_h^P`.

Partner participation value uses `rho_h + x_h + beta n_h^F`, with `x_T=0`.

Do not impose `alpha=beta` before Stage 4 unless symbolic simplification requires it. Stage 4 should first inspect whether only the product `alpha beta` matters. If so, normalize one coefficient.

B4 fixes the feedback side by setting `beta=0` or equivalently fixing partner participation responses.
