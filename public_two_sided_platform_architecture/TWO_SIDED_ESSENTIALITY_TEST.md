# Two-Sided Essentiality Test

Set `beta=0` while preserving project choice and public partner-side investment. Then

`n_i^P=rho+x_i`, `n_T^P=rho_T`.

The private platform still has ordinary price competition with public platforms, so a private-price response may remain. What disappears is the recursive chain

`firm demand -> partner participation -> firm value`.

Therefore two-sidedness is **not mechanically guaranteed essential**. The selected architecture only passes Stage 3 because `beta>0` adds a distinct endogenous network term to `D_T` and to the government's cross derivative.

Stage 4 fatal test: if the same qualitative P2-R theorem holds at `beta=0`, kill the two-sided contribution.
