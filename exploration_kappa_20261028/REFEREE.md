## 2. 最も有望な命題の内容と限界

固定された相手地域の参加状態の下で、私的R&D誘因を `h theta` と書き、`h=0` の近傍を調べる。
`d=Delta`, `0<U<d`, `c=(d-U)/(2d)` とする。
`mu(z)=E[theta|z]`、`v(z)=Var(theta|z)` が境界 `z=c` で必要な正則性を満たすと、局所価格と参加の反応は

```text
f_h = [mu(c)+(1-c)mu'(c)]/2,
m_h = [mu(c)-(1-c)mu'(c)]/(2d),
q_h = v(c)/d + mu(c)m_h,
r_h = c m_h.
```

で整理される。
ここで微分は `h=0+` であり、相手地域の価格や参加状態の変化は含まない。
価格の一階条件 `m+f m_f=0` と、閾値の移動による境界積分から得られる。
`q_h` の分解の正の分散項は、同じ参加人数の下でより高い技術能力が選ばれる効果である。
この項は混合分布の対角線上の特異成分を必要としない。

混合分布では `mu(c)=(1-kappa)/2+kappa c` なので、参加反応の符号は

```text
m_h = [1/4+kappa(c-3/4)]/d,
kappa_m = 1/(3-4c)
```

で変わる。
条件付き分散が正なら、`m_h=0` でも `q_h>0` となる。
理論担当の証明を確認したところ、`q_h` の分子は厳密凸の二次式であり、両端の符号と境界分散から一意な閾値 `kappa_q>kappa_m` が得られる。
従って開いた相関区間で `m_h<0<q_h` が生じる。
この中間領域は、現行の完全整列モデルでは観察できない。
単一の数値点を使わずに区間を証明できることは、この拡張の最も良い点である。

ただし、経済原理の一般化対象は「Pearson相関そのもの」よりも、選別境界における条件付き能力の水準、勾配、分散である。
相関係数だけを等しくしても、一般のコピュラでは `mu'(c)` は定まらない。
したがって混合分布の `kappa_m` を、任意の同一相関分布に通用する政策閾値として解釈できない。
局所分解が別の滑らかな分布でも成立することと、相関閾値や均衡反転が分布横断的に保たれることは、別の主張である。

## 3. 新規性を誤認しやすい点

| 候補主張 | 査読判定 |
|---|---|
| 完全整列を緩めて `q=phi(m)` が破れたので新しい経済理論である | 不十分。仮定の変更による識別制約の解除であり、それ自体は命題上の貢献ではない。 |
| `m,q,r` は自由に動く三つの独立状態変数になる | 過大。固定した相手状態と分布の下では一つの料金閾値で参加集合が決まり、単調な `m(t)` を反転すれば `q=Q(m;h,kappa)`, `r=R(m;h,kappa)` と書ける。破れるのは相手状態によらない普遍的な `phi` である。 |
| 相関低下は公的サービスの価値を常に高める | 根拠なし。直接便益、人数、技術能力総量、地域別製品市場損益が異なる符号で変わる。 |
| 相関ゼロなら技術能力選別がない | 誤り。`h>0` なら参加条件そのものが `theta` に依存する。 |
| 相関による参加比較静学の符号閾値 | 有用なモデル内命題。一般的な料金選別機構との衝突監査が必要。 |
| 人数減少と能力総量増加の同時発生 | 有望。人数と平均能力の逆行より強いが、境界分散を使う一般的な選別分解の特殊化でもある。 |
| 地域別と全国の公的参入閾値が違う | 既存の外部性会計に吸収される一般原理。相関が外部性の構成をどう変えるかが追加対象。 |
| 元パラメータで政府参入の反転が見えた | 数値的存在例。連続な利得が既存の費用付近で交差するだけでは、新しい一般均衡定理にならない。 |
| 全配置のコード実行とLeanの保持 | 信頼性の証拠。経済学上の新規性の代替にはならない。 |

Hagiu型の質加重参加、二次元選別、価格による内生的構成という先行研究の一般原理と、今回の閉形式閾値は明確に区別すべきである。
既存研究の特定の定理に本結果がそのまま含まれるという主張も、本文と仮定の対応を示すまでは認証できない。

## 4. 分布依存性の監査

混合分布の適合性は、価格と参加の計算を透明にする点にある。
一方、`kappa` を増やすと対角線上の特異的な人口比率も増えるため、単なる「滑らかな依存の強化」と同一視できない。

例えば `h>0`, `L=d+h` として私的な総評価 `X=d z+h theta` を考える。
混合分布では `X` の左端密度は `kappa/L` である。
固定 `U` の下での全員参加価格の最適性に現れる `kappa U >= L` 型の条件は、この端点密度に直接依存する。
結合密度が有界で滑らかな二次元分布なら、一般に左端での `X` の密度はゼロになり、全員参加の料金屈曲点の結論が変わりうる。
この類の閾値を主たる相関政策命題として昇格させるべきではない。

他方、上記の局所分散分解は対角線上の人口を要しない。
たとえばFGM族の許容相関域では、混合分布と同じ線形な条件付き平均を持つ滑らかな分布を作れる。
ただしFGMの相関範囲は限定され、混合分布の全区間の符号反転をそれだけで検証したことにはならない。

## 8. 同一相関で符号が逆転する厳密反例による最終補足

相関だけを政策診断に使うことへの反例を、主担当の提案から独立した有理数演算で確認した。
`g(z)=6z^2-6z+1`, `beta(kappa)=4kappa(1-kappa)` として、次の一パラメータ族を考える。

```text
C_alt,kappa = kappa M + (1-kappa) H_kappa,
h_kappa(theta,z)=1+beta(kappa)(2theta-1)g(z).
```

`M` は完全正相関分布である。
`|beta|<=1`, `|2theta-1|<=1`, `|g|<=1` なので密度は非負である。
`integral g=0`, `integral z*g=0` なので両周辺分布は一様で、`H_kappa` の共分散はゼロである。
従って `Corr(C_alt,kappa)=kappa` である。
両端は元の混合族と同じ独立分布と完全整列分布になる。
新しい自由パラメータもない。

この族の局所反応と元の混合族の差は

```text
d (m_h,alt-m_h,mix)
 = (1-kappa) beta(kappa) [g(c)-(1-c)g'(c)]/12.
```

`c=1/4`, `kappa=13/25` を取ると、厳密に

```text
d m_h,mix = -1/100,
d (m_h,alt-m_h,mix) = 1326/15625,
d m_h,alt = 4679/62500 > 0.
```

となる。
同一の相関係数、一様周辺、同じ両端を持つ一パラメータ族でも、補完性に対する参加人数の局所反応の符号は異なる。
これは先行研究による吸収の証明ではない。
混合族で得た相関閾値をコピュラ横断的な経済法則と主張できないことの反例である。
混合族内の三領域命題や、一般条件付き分散分解の正しさは損なわない。
反例の係数は元のモデルの数値較正を変更するためのものではなく、分布に関する一般命題を否定するための数学的な証人である。

この反例によって、上位誌移行NO-GOを維持する。
完成した成果を保存した後はモデルを複雑化せず、この最小拡張の探索を停止することが妥当である。
残存する本文未確認文献と、一般的な選別分解の命題優先権は未解決のまま記録する。


## 9. 完成した検証結果を踏まえた判定

数値担当の報告は、三つの元シナリオの全16配置について、`kappa=1` の数値差が浮動小数点丸めの水準であり、モデル式も有理数恒等式として一致すると記録している。
元のStage 11Rの証明群も回帰実行されている。
凍結研究の保護と再現性については、今回の探索は要求を満たしている。

元のskill、`lambda=1/2` シナリオでは、相手Aが全員参加する条件付きB政府参入閾値が相関に厳密増加し、既存固定費用と一度交差することが有理数とBernstein係数の符号で証明された。
閾値の交点は約 `kappa=0.9351610109823004` である。
したがって「相関低下は常に公共サービスの価値を高める」という方向は、この元パラメータ例では反対になる。
これは費用を事後に調整した反転ではない点で、単なる任意費用交差より説得力がある。

しかし、同じ報告は `kappa<1` のP/P価格継続について有限の偏差グリッド、局所精密化、複数初期値という数値診断にとどまると明記する。
従って連続した相関域全体の四主体SPNE反転は証明済みではない。
また、条件付き閾値の変化幅は元の厚生単位で約 `0.00048824` と小さく、既存の狭い費用帯の問題を解消する一般理論結果には至らない。

文献担当はVeiga and Weyl (2011)の原著、Veiga, Weyl and White (2017)の本文と公式付録の証明を確認した。
これにより、多次元の嗜好と他者への貢献、限界参加者の条件付きモーメント、多次元の集計量という一般原理については、単に未調査という状態を脱して既存研究との強い衝突が確認された。
一方、今回の二閾値の順序そのものが原典に書かれていることや、今回の特異混合と四主体ゲームが原典の全定理の特殊ケースであることまでは認証されていない。
Hua (2016)本文とQJE (2016)最終版の完全監査は未確認として残る。

代替コピュラ反例が否定するのは「Pearson相関が等しければ符号閾値も等しい」という主張である。
独立から完全整列へ連続につながる広い分布族で、局所参加反応の符号の転換が少なくとも一つあるという存在論までは否定しない。
Gaussian族について理論担当の連続性議論もこの区別に沿っている。
この意味で、有効なモデル内の新命題候補は見つかった。
しかし、そのことと上位誌に値する非吸収的な主貢献の発見は同一ではない。

最終判断は、**最小拡張の探索を停止し、JICT向け凍結研究を保持する。上位誌向け拡張の採用は見送る。**
停止理由は、標準的な選別原理から十分に離れた一般均衡と政策の命題を認証できず、条件付き反転の規模と分布依存性も残るためである。
これを解消するためにモデルの自由度を増やすことは、今回のミッションに反する。
