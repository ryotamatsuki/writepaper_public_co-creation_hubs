# Regional Welfare Derivation

In the central public–metro–public regime define

`A_1 = integral_0^{theta_1T} x_1[d-u theta] dtheta`
`= [x_1^2 d^2-q^2]/(2u x_1)`,

`A_2 = integral_{theta_2T}^1 x_2[c+u theta] dtheta`
`= [x_2^2 d^2-q^2]/(2u x_2)`,

and `L=theta_2T-theta_1T`.

For one home-region project population, project-side net surplus is

`P=A_1+A_2+qL-kappa`.

The two home regions have identical type distributions. Every project matched through local Hub `i` generates the same expected partner-side benefit as its project-side local match value, so region `i` receives partner incidence `2A_i` from the two project populations.

Hence

`W_1=P+2A_1-gamma x_1^2/2`,
`W_2=P+2A_2-gamma x_2^2/2`.

No prestige or market-share term appears.

At fixed `q`,

`dW_1/dx_1=[3d^2 x_1^2+q^2-2 gamma u x_1^3]/(2u x_1^2)`,

and

`d^2W_1/dx_1^2=-gamma-q^2/(u x_1^3)<0`.

In this active fixed-offer regime the expression is independent of `x_2`, which drives the B3 zero-cross-effect result.
