`x_1 -> p_T*(x_1) -> W_1 -> x_1`,

so private price discipline of **own** public investment is not a three-player result.

`x_2 -> p_T*(x_1,x_2) -> W_1 -> x_1`

inside that separated allocation regime.

Therefore the second public player is **ESSENTIAL** to the triadic coupling candidate, not merely a duplicated player count.
