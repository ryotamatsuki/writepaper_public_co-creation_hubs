# Metro Price Solution

Use `q=m-p_T`. With zero private marginal monetary cost, profit in the central interior regime is

`Pi_T=2(m-q)(x_1+x_2)(q-K)/(u x_1 x_2)`.

The unique interior stationary point is

`q*=(m+K)/2`,
`p_T*=(m-K)/2`.

SOC is strictly negative because the demand slope is positive and constant on the segment.

This re-derives the Stage 3 pre-check: no correction is required. `kappa` cancels from provider comparisons but restricts validity through `q*>kappa`.

## Other clipping segments

If only one public tail survives, private demand is affine with floor equal to that surviving public line's minimum endpoint, producing the familiar midpoint stationary candidate. If metro covers the entire market, profit is decreasing in `q`, so the optimum is at the lowest `q` supporting monopoly. The global optimum is the best feasible candidate among segment stationary points and clipping kinks.

## Positive private marginal cost

For `Pi_T=(p_T-c_T)D_T`, the central solution becomes

`q*=(m-c_T+K)/2`,
`p_T*=(m+c_T-K)/2`.

The public-investment comparative-static signs below are unchanged. Normalizing `c_T=0` is therefore qualitative-only.
