# Asymmetric Equilibria / Off-Symmetric Diagnostics

No asymmetry parameter is introduced. Under symmetric primitives, Stage 4 does not claim existence of an asymmetric SPNE.

The off-symmetric cross-partial is nevertheless informative:

`C_G=-a[a x_1x_2(x_1+7x_2)+2m(x_2^2-x_1^2)]/[4u(x_1+x_2)^4]`.

If `x_1<=x_2`, `C_G<0` immediately. If `x_1>x_2`, complementarity requires a sufficiently high metro value relative to the weaker public capability.

In 100,000 admissible central-regime state draws, `C_G` was negative 99,282 times and positive 718 times. B2 was positive 2,114 times. There were 1,396 states with B2 complementarity but G substitution, and zero sampled states with B2 substitution but G complementarity.

A targeted root search did not provide a robust asymmetric interior equilibrium suitable for a theorem, so no multiplicity/asymmetric-equilibrium headline is asserted.

The off-symmetric sign variation is therefore a counterexample tool, not evidence sufficient to pass the full-game novelty gate.
