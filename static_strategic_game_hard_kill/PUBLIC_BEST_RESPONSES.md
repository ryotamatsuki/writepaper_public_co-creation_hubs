# Public Best Responses and Strategic Interaction — P2

For a twice-differentiable interior best response,

`dBR_1/dx_2 = -W_{1,12}/W_{1,11}`.

Relevant SOCs are negative in the central regimes, so the cross-partial determines the sign.

## B2

`W_{1,12}^{B2}=x_1x_2 a^2(x_1-5x_2)/[u(x_1+x_2)^4]`.

At symmetry: negative, hence substitutes.

## B3

`W_{1,12}^{B3}=0` in the active public–fixed-metro–public regime.

## G

`W_{1,12}^{G}=-a[a x_1x_2(x_1+7x_2)+2m(x_2^2-x_1^2)]/[4u(x_1+x_2)^4]`.

At symmetry this equals `-a^2/(8ux)`: substitutes.

For `x_1>x_2`, G can become complementary only if

`m > a x_1x_2(x_1+7x_2)/[2(x_1^2-x_2^2)]`.

The active-regime upper bound on `m` implies such complementarity requires strong capability asymmetry; it does not create complementarity in a region where B2 is necessarily substitutive. Numerical state draws found B2-complement/G-substitute cases, but no B2-substitute/G-complement cases.

Without partner incidence (W1 counterfactual), G has

`W_{1,12}^{W1}=-3x_1x_2 a^2/[4u(x_1+x_2)^3]<0` globally in the central regime.

**P2 classification: TRUE as a strategic-feedback result; contribution KILL because the entire expression follows from the characteristic-space isomorphism.**
