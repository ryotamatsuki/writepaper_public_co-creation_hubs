# Full-Game-Only Result Test

## Algebraic candidate that genuinely requires G

In the active public–metro–public regime:

- B1 has no rival public government;
- B3 has `W_{1,12}=0` because a fixed metro interval separates the public margins;
- G has a nonzero price-mediated cross-effect because `q*=q*(x_1,x_2)`.

The exact G cross-partial is

`C_G=-a[a x_1x_2(x_1+7x_2)+2m(x_2^2-x_1^2)]/[4u(x_1+x_2)^4]`.

This is a real triadic strategic channel `x_j -> p_T* -> allocation -> W_i -> x_i`.

## Why it does not pass the Stage 4 contribution gate

1. At symmetry, G and B2 are both strategic substitutes; G merely changes the magnitude (`B2=-a^2/(4ux)`, `G=-a^2/(8ux)`).
2. Off symmetry, sign variation is possible, but the same sign-switch logic is already present in B2 and no equilibrium sign-reversal theorem was established.
3. Most importantly, the complete payoff system is exactly reparameterizable as a linear characteristic-space game. The triadic cross-effect therefore does not use a matching-specific primitive.

The full game **does** add an endogenous strategic link relative to B3, so the failure is not “nothing happens.” The failure is that the surviving economics is generic differentiated-facility competition rather than a productive-matching theorem.

Result-level classification: **ALGEBRAIC FULL-GAME EFFECT SURVIVES; MATCHING CONTRIBUTION DOES NOT.**
