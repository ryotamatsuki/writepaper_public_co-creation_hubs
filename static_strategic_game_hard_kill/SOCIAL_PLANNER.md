# Social Planner

The frozen Stage 3 model specifies a local partner-side surplus but only a project-side metro match value. Stage 4 therefore uses the strict accounting implied by those primitives rather than inventing a metro-partner benefit.

In the full-participation public–metro–public regime,

`SW=4(A_1+A_2)+2mL-2kappa-gamma(x_1^2+x_2^2)/2`.

Metro fees cancel against private profit at the national level.

The planner benchmark is a central public-investment planner choosing `(x_1,x_2)` while anticipating the private metro best response `p_T*(x_1,x_2)`; it does not control the private price.

At symmetry, with `B=12c^2+28cu+15u^2`, the planner marginal is

`F_SP^G=[B x^2-8 gamma u x^3-4m^2]/(8u x^2)`.

This expression is only valid while the induced allocation remains in the central active regime; global planner comparisons require checking adjacent clipping regimes and KKT boundaries.

The Stage 4 verdict does not depend on extending planner analysis outside that regime because the matching-specificity gate fails earlier.
