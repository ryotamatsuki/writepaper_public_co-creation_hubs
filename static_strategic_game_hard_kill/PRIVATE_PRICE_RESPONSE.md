# Private Price Response — P1

In the central interior regime,

`K=a x_1 x_2/(x_1+x_2)`, `a=2c+u`,

and

`p_T*=(m-K)/2`.

Therefore

`dp_T*/dx_1 = -a x_2^2/[2(x_1+x_2)^2] < 0`,

`dp_T*/dx_2 = -a x_1^2/[2(x_1+x_2)^2] < 0`.

Equivalently, the project's metro gross offer `q*=m-p_T*` rises with either public investment.

At symmetry, `dp_T*/dx_i=-a/8`.

The numerical hard-kill search produced 100,000/100,000 negative derivatives in admissible central-regime state draws.

**P1 classification: TRUE, but not a headline contribution.** It is the standard price response to a stronger outside competitive option and is already conceptually close to mixed-platform and mixed-oligopoly pricing results.
