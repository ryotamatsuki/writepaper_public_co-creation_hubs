# Canonical Institutional Class

- `G_i`: regional/local government.
- `H_i`: regional public innovation hub/intermediary.
- `H_T`: shared metropolitan private innovation hub.
- `x_i`: regional public facilitation capacity (coordinators, matching, events, partner recruitment, programme quality).
- `p_T`: effective paid membership/access price for the metropolitan innovation-intermediation bundle.
- `n_h^F`: focal projects using route `h`.
- `n_h^P`: partners/investors/experts/support organizations associated with `h`.

Canonical wording is **regional public innovation hubs and a shared metropolitan private innovation hub**. “National private platform” is not canonical; Stage 7 established that national→metropolitan is interpretation refinement only, not a model change.

Project single-homing is project-level primary-route choice. Partner multihoming is non-exclusive institutional plausibility, not a universal empirical fact.
