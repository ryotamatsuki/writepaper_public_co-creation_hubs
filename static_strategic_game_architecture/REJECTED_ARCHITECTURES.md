# Rejected Architectures

- **A finite capability + project value:** rejected baseline due to step-like demand and public BR kinks; retain as robustness if continuous model survives.
- **B order-statistic sampling:** rejected due to nonessential algebraic burden in a three-stage game.
- **C unrestricted continuous screening:** rejected because tractability is obtained by hiding partner geometry in `q_i`.
- **E correlated match-value draws:** rejected because correlation between unchosen hubs has no independent role under exclusive ex-ante choice and no referral/multihoming.
- **F vector capabilities:** rejected due to parameter explosion and multidimensional threshold geometry.

No rejection is based on failing to produce a desired sign.
