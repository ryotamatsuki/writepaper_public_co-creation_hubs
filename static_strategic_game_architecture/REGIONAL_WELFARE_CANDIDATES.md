# Regional Welfare Candidates

## W1 — resident project surplus only
Minimal and tractable, but ignores why attracting projects to a regionally anchored partner ecosystem has regional incidence. It also biases the decentralization wedge toward free-riding/underinvestment.

## W2 — resident project surplus + resident-partner surplus — SELECTED

Each successful local match creates one normalized project-side benefit and one normalized partner-side benefit. This is a fixed normalization, not strategic bargaining and introduces no free incidence parameter.

For region `r`,

`W_r = resident-project real/net surplus + partner-side surplus generated through H_r by projects from either region - gamma x_r^2/2`.

A metro access fee paid by a resident project is a regional outflow because the private intermediary is metropolitan/national rather than owned by region `r`.

This objective gives a genuine regional business-stealing/incidence margin while remaining parameter-parsimonious.

Stage 4 must also report W1 as a counterfactual if W2 drives a headline sign.
