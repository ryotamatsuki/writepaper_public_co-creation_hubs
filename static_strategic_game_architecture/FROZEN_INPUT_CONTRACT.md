# Frozen Input Contract

Stage 3 inherits Stage 2R-MC-G without changing the research question.

Frozen: two regions; `G_1,G_2`; public hubs `H_1,H_2`; metro private `H_T`; immobile heterogeneous projects; partner ecosystems; public strategies `x_1,x_2`; private strategy `p_T`; choice `{H_1,H_2,H_T,0}`.

Baseline timing remains `(x_1,x_2) -> p_T -> project choice -> matching` unless Stage 4 proves a feasibility problem.

Prohibited: dynamics, ecosystem accumulation, referral, diagnosis, relocation, Cournot/product-market competition, Hotelling/logit tastes, arbitrary `-gamma x_1x_2`, bargaining, multihoming, public prices, endogenous metro quality, endogenous partner entry, strategic ecosystem design.

PR #21 is a negative benchmark for a different referral/Cournot architecture. PR #22 is historical pre-v1.1 evidence. PR #23 is the binding Stage 2 dependency.
