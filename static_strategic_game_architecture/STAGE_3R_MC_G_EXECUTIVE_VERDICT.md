## Verdict

\[
\boxed{\textbf{GO — MINIMAL STATIC GAME SELECTED}}
\]

Six economically distinct matching architectures were screened. The selected architecture is **Common–Specialist Compatibility-Density Screening (CSDS)**: a one-dimensional technological project need `theta in [0,1]`, mirrored regional partner-compatibility profiles, continuous public screening capability `x_i`, and a fixed broad metropolitan matching technology priced strategically by `H_T`.

The selection is not based on expected theorem direction. It is selected because it simultaneously: (i) preserves project-partner fit, (ii) resists collapse to one scalar facility quality, (iii) gives smooth public-public sorting, (iv) gives a nondegenerate interior private pricing problem, and (v) nests B1/B2/B3/G by player removal or price fixation.

In the interior metro-demand region, the pre-check yields

\[
p_T^*=\frac{m}{2}-\frac{(2c+u)x_1x_2}{2(x_1+x_2)},
\]

and therefore

\[
\frac{\partial p_T^*}{\partial x_1}=-\frac{(2c+u)x_2^2}{2(x_1+x_2)^2}<0,
\quad
\frac{\partial p_T^*}{\partial x_2}<0.
\]

This proves only tractability and strategic relevance of endogenous metro pricing, not a paper-level proposition.

## Selected core

- project need: `theta ~ U[0,1]` in each region;
- regional compatibility intensity: `w_1(theta)=c+u(1-theta)`, `w_2(theta)=c+u theta`;
- metro expected project-side match value: `m`;
- public expected project-side match value: `M_i=x_i w_i(theta)`;
- common real coordination cost `kappa` for using any intermediary;
- public cost `C(x_i)=gamma x_i^2/2`;
- firm choice among `H_1,H_2,H_T,0`;
- baseline timing `(x_1,x_2) -> p_T -> choice -> matching`;
- equilibrium concept: SPNE.
