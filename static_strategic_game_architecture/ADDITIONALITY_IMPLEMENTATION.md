# Additionality Implementation

For any comparison of `x_i` with a lower-capability counterfactual, project types can be classified by provider/outside-option switches.

- ADD1: `0 -> H_i` and realized expected productive surplus becomes positive net of coordination cost.
- ADD2: `H_j/H_T -> H_i` with higher total real productive surplus.
- ADD3: `H_j/H_T -> H_i` with unchanged or lower total productive surplus: displacement/duplication.
- ADD4: total real surplus approximately unchanged but project/partner/metro-rent incidence changes across regions.

The classification follows provider thresholds generated by the model; no extra state variable is added. The decomposition is descriptive unless Stage 4 derives a primitive-based threshold/result.
