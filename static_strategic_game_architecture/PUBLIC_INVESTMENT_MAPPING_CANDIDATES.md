# Public Investment Mapping Candidates

Considered: number of draws; evaluation precision; Poisson discovery rate; and effective-screening probability.

**Selected:** `x_i in [0,1]` is effective screening/evaluation capability. Conditional on project need `theta`, a productive local opportunity is identified with probability `x_i w_i(theta)`, under `0<c<c+u<=1`.

Normalize the project-side benefit of a successful productive match to one. Then

`M_i(theta,x_i)=x_i w_i(theta)`.

This is exact under the one-evaluation success technology, not a first-order Poisson approximation. Cost is `C(x_i)=gamma x_i^2/2`, `gamma>0`.

Rejected mappings: integer draw counts (discrete investment), unrestricted precision functions (reduced form), and endogenous partner-pool design (prohibited strategic ecosystem design).
