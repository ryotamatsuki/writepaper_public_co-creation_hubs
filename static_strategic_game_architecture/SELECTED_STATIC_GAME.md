# Selected Static Game — CSDS

## Players and project populations
Two regions `r=1,2`, each with unit mass of immobile projects. In each region, technological need `theta ~ U[0,1]`.

Strategic players: regional governments `G_1,G_2` and metro private intermediary `H_T`.

## Partner ecosystems
Local compatibility intensities:

`w_1(theta)=c+u(1-theta)`;
`w_2(theta)=c+u theta`;

with `0<c<c+u<=1`, `u>0`. `c` is the common/generalist component; `u` is specialist composition.

Metro expected project-side match value is constant `m`, `0<m<=1`, representing broad fixed national coverage.

## Productive match value / screening
A successful compatible local match yields one normalized unit of project-side benefit and one normalized unit of local-partner benefit. Hub `i` successfully identifies such a partner with probability `x_i w_i(theta)`, where `x_i in [0,1]` is effective screening/evaluation capability.

Therefore

`M_i(theta,x_i)=x_i w_i(theta)`, `M_T(theta)=m`.

## Firm payoffs
A real coordination/implementation cost `kappa>0` is incurred if any intermediary is used.

`U_i=M_i-kappa`,
`U_T=m-p_T-kappa`,
`U_0=0`.

Each project chooses the highest payoff, with measure-zero ties resolved by a fixed rule that does not affect aggregate results.

## Public cost
`C(x_i)=gamma x_i^2/2`, `gamma>0`.

## Regional welfare
Region `r` counts: (i) real/net surplus of its resident projects from whichever provider they use; (ii) partner-side surplus generated by all projects matched through `H_r`; (iii) minus public investment cost. Metro fees paid by resident projects are regional outflows.

No hub-market-share or prestige utility is included.

## Private profit
`Pi_T=p_T D_T`, baseline private marginal monetary cost normalized to zero.

## Timing
1. `G_1,G_2` choose `x_1,x_2` simultaneously.
2. `H_T` observes them and chooses `p_T`.
3. projects choose `{H_1,H_2,H_T,0}`.
4. matching realizes.

## Equilibrium
Subgame-perfect Nash equilibrium.

## Minimum restrictions
`0<c<c+u<=1`, `0<m<=1`, `gamma>0`, `kappa>0`, `x_i in [0,1]`, `p_T>=0`. Additional inequalities defining an interior allocation/pricing regime must be derived, not assumed globally, in Stage 4.
