# First-Best / Second-Best Distinction

- **Decentralized Nash:** each `G_i` chooses only `x_i`; private `H_T` chooses `p_T`.
- **Coordinated-public second best:** a public coordinator chooses `(x_1,x_2)` but `p_T` remains the private best response.
- **Full first best:** a social planner controls all real allocations/investments. Treating `p_T` as a welfare instrument is redundant for national surplus because it is a transfer, unless it is used to decentralize an allocation.

The Stage-7 welfare comparison uses the coordinated-public benchmark. It does not call that benchmark first best.
