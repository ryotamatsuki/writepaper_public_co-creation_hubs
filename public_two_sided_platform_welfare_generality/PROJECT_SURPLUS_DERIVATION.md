# Project Surplus Derivation

For each region in the central regime, types `z<s` choose outside, `s<z<t_i` choose `H_T`, and `z>t_i` choose `H_i`.

Hence exact project surplus is

`PS_i = ∫_s^{t_i}(zq_T-a)dz + ∫_{t_i}^1(zq_i-kappa_L)dz`

`= q_T(t_i^2-s^2)/2-a(t_i-s)+q_i(1-t_i^2)/2-kappa_L(1-t_i)`.

No triangular-CS shortcut is used. Because utility is quasi-linear in the frozen model, this integral is the exact resident project surplus over the relevant choice envelope.
