# Welfare Threshold Analysis

No new global welfare threshold is certified.

The analytically valid local objects are:
- strict public SOCs;
- nonsingular participation/cutoff Jacobian;
- private price SOC;
- strict P2-R4 inequalities;
- the sign of `E_ij+dPi_T/dx_i`.

A welfare threshold would require tracking all project-choice regimes because the coordinated-public optimum approaches the central-regime boundary at the witness. Reporting an interior threshold from the smooth regime alone would be false precision.
