# Nested Benchmark Map

The following are exact restrictions **of the candidate model**. Their correspondence to published papers is often an analogy rather than an exact mathematical nesting until Stage 3 chooses functional forms.

| Benchmark | Candidate restriction | Closest literature | Exact nesting into published model? | Full game potentially adds |
|---|---|---|---|---|

## Stage 3 obligation

Stage 3 must specify functional forms/matching primitives so that `B1,B2,B3,G` can be solved on the same primitive space. It must not falsely label Kim, Liu, Takahashi, or Damiano–Li as exact nested cases unless algebraic restrictions genuinely reproduce their models.

## Stage 4 contribution test

The full model earns theoretical credit only if at least one headline object differs substantively from every benchmark, e.g.:

- a best-response slope or strategic-complement/substitute switch;
- a private price-response threshold;
- a creation/quality/displacement partition threshold;
- a Nash-vs-planner over/underinvestment reversal;
- an equilibrium region or ranking unavailable in `B1-B3`.

If `G` is only the union of benchmark results, the generalization claim is `NO-GO`.
