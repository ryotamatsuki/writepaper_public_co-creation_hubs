# Frozen Research Question and Scope

## Research question

**English**

> When does a locally financed public co-creation hub generate positive additional value for local firms and regional welfare when firms can also access competing public hubs in other regions and a metropolitan private matching intermediary?

**Japanese**

> 地方企業が他地域の公共拠点や東京等の民間拠点を利用できるにもかかわらず、地方政府が自地域に官民共創拠点を整備・強化することが有効となるのは、どのような条件か。

## Frozen institutional architecture

- Two regions `i in {1,2}`.
- Regionally immobile firms/projects. The project chooses an intermediary, not a location.
- Regional governments `G_1,G_2`.
- Regional public matching hubs `H_1,H_2`.
- One metropolitan/national private intermediary `H_T`.
- Regionally anchored heterogeneous partner opportunity sets `S_1,S_2,S_T`.
- Productive match fit is the allocation primitive.
- Firms/projects choose among `H_1,H_2,H_T,0`.
- Public objectives are regional welfare; private objective is profit.

## Frozen static strategy architecture

- `G_i` chooses costly matching/screening capability `x_i >= 0`.
- `H_T` chooses access price `p_T >= 0`.
- Local public access price is normalized to zero.
- Baseline timing: `(x_1,x_2)` simultaneously, then `p_T`, then firm/project choice, then matching realization.

## Prohibited baseline additions

No dynamic reputation, ecosystem accumulation, installed base, tipping, learning, referral, diagnosis, failed-match routing, firm relocation, downstream Cournot, Hotelling/logit taste differentiation, arbitrary `-gamma x_i x_j`, endogenous metropolitan quality, bargaining, multihoming, endogenous public access prices, or binary public provision choice.
