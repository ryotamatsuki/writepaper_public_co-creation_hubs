# Threat T4 — Outside-Option Triviality Test

## Question

Does the metropolitan intermediary act only as a scalar outside option

\[
M_T(\theta)-p_T,
\]

so that endogenizing `p_T` changes levels but creates no economically new strategic feedback?

## Stage 2 status

\[
\boxed{\textbf{UNRESOLVED — FORMAL TEST REQUIRED}}
\]

Prior art already establishes that private fees can respond strategically to public platform competition. Therefore `p_T^*` itself is not a contribution.

## Required B3 vs G experiment

Stage 3/4 must solve on the same primitives:

- `B3`: `p_T=bar p` fixed;
- `G`: `p_T=p_T^*(x_1,x_2)` endogenous.

Then compare at least:

1. public best-response slopes;
2. equilibrium public investments;
3. project creation/quality/displacement partitions;
4. Nash-versus-planner wedge;
5. threshold/ranking structure.

## Kill rule

If replacing `p_T^*(x_1,x_2)` by a suitable constant `bar p` preserves all headline qualitative results and the endogenous price merely changes a scalar cutoff, the metropolitan strategic layer is not carrying theoretical value.

## Survival rule

The layer survives only if the private response changes a substantive strategic or welfare result—e.g., sign/ranking/threshold/equilibrium region—not merely numerical levels.
