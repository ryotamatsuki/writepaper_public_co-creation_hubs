# Static Model Survival Contract

## Authorized next stage

\[
\boxed{\textbf{Stage 3R-MC-G — Minimal Static Strategic Game Architecture Selection}}
\]

No Stage 4 algebra is authorized until Stage 3 selects one tractable common primitive structure.

## Stage 3 must select

1. exact productive matching primitive;
2. minimum project heterogeneity;
3. exact representation of `S_1,S_2,S_T`;
4. exact mapping from `x_i` to evaluated/found partner opportunities;
5. exact regional welfare and investment cost;
6. exact metropolitan demand and profit;
7. exact timing and tie/corner rules;
8. restrictions generating `B1,B2,B3,G`;
9. a minimal candidate-proposition set.

## Required candidate propositions

Stage 3 should target, without assuming their signs:

- private response `dp_T^*/dx_i`;
- public strategic-response slope accounting for the private-price channel;
- project-type partition into creation/quality/displacement/unaffected groups;
- decentralized versus planner investment wedge;
- at least one condition under which the full game differs qualitatively from B1-B3.

## Immediate kill conditions

Return `NO-GO` if:

- partner opportunity sets collapse to scalar generic quality without loss;
- endogenous metro price is strategically trivial relative to B3;
- the second regional government is a mechanical duplicate with no new interaction;
- full-game candidates are only familiar monotone comparative statics;
- meaningful results require prohibited rescue features;
- the static architecture fails and the only proposed rescue is the reserved dynamic ecosystem mechanism.

## Prohibited changes remain frozen

No dynamics, reputation, ecosystem accumulation, tipping, referral, diagnosis, relocation, Cournot, Hotelling/logit tastes, arbitrary competition cross term, endogenous `x_T`, bargaining, multihoming, public access pricing or fixed provision choice.

## Reserved extension

If and only if the static game survives, later work may study

`successful matching -> future partner entry/ecosystem accumulation -> future matching advantage`.

This is not available as Stage 3 model rescue.
