# Generalization / Unification Value Test

## v1.1 standard

The candidate does not earn novelty because no paper was found with the exact words “two regional public hubs plus one metropolitan private hub.” A valid generalization must:

1. define transparent benchmark restrictions;
2. recover benchmark economics correctly;
3. make an interaction endogenous that is absent from each benchmark;
4. generate at least one full-model-only theorem/threshold/ranking/reversal/equilibrium region/conditions result/welfare wedge.

## Candidate benchmark logic

- `B1`: one local public matching investor versus the private metro intermediary.
- `B2`: two local public matching investors, no private metro intermediary.
- `B3`: two public matching investors plus a nonstrategic fixed metro outside option.
- `G`: two public matching investors plus a strategically pricing metro intermediary.

## Potential generalization value

The full game may answer a question no single benchmark answers:

> How does a national private intermediary's optimal price response modify decentralized interregional public investment competition when users choose providers according to productive project-partner fit?

That question is meaningful only if the interaction changes results.

## Minimum Stage 4 success bar

At least one result must satisfy all:

- depends on both `x_j` and endogenous `p_T^*`;
- changes/disappears when either the second public hub or strategic private pricing is removed;
- is not an immediate corollary of Takahashi, Damiano–Li, Kim/Liu, or standard mixed oligopoly;
- has an interpretable primitive condition, preferably connected to project/partner opportunity geometry.

## Current verdict

`POTENTIALLY VALUABLE GENERALIZATION — NOT YET A CONTRIBUTION`.

Stage 3 is authorized to construct the minimal common primitive environment. Stage 4 is the actual kill gate.
