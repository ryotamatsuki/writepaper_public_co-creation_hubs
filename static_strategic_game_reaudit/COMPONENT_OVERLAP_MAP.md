## Core conclusion

The project has **no defensible ingredient-count novelty claim**. Its only possible theory contribution is an equilibrium/welfare result generated by the interaction of familiar components in a strategically non-equivalent full game.

Therefore all prose such as “we introduce public/private asymmetry,” “we allow matching investment,” or “we distinguish creation from displacement” must be treated as model description, not contribution.
