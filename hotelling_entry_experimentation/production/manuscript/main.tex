\begin{abstract}
Can publicly financed basic innovation services change whether private specialist intermediaries enter when cross-region collaborations generate competing new products? We develop a two-region sequential game with two independent public and two private entry decisions. Private fees screen founders by technical ability, so participation mass and the unnormalised skill moment respond differently; matched ventures then generate geographically differentiated consumer, incumbent and founder payoffs. The model connects these familiar mechanisms to local entry incentives and a restricted two-region welfare comparison. In an exactly checked baseline, greater skill complementarity changes the decentralised configuration from public--private coexistence in one region and private-only provision in the other to coexistence in both. An equal-mean homogeneous innovation technology does not generate the latter configuration, although the restricted planner selects it in each comparison. The switch is highly parameter-sensitive: the relevant public-cost interval spans about 1.21 percent of the baseline fixed cost, and an alternative skill distribution does not reproduce it. The result is a bounded equilibrium illustration, not a general rule favouring public ownership or physical innovation hubs.
\end{abstract}
