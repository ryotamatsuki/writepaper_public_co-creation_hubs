# Minimality Audit

| Primitive | Classification | Removal effect |
|---|---|---|
| Two regional governments | ESSENTIAL | no bilateral gateway interaction without them |
| Binary gateway choice | EQUILIBRIUM ESSENTIAL | defines the entry/provision game and `D_0,D_1` |
| Homogeneous Cournot competition | ESSENTIAL FOR CURRENT CANONICAL MODEL | explicit firm rivalry and endogenous profits disappear without it |
| Ecosystem engagement `x_i` | ESSENTIAL | no endogenous gateway-to-productivity channel |
| Shared-core network strength `beta` | ESSENTIAL FOR NETWORK-INDUCED COMPLEMENTARITY | under regional welfare, `beta=0` implies `Gamma^C<0` throughout the stable domain |
| Own gateway access improvement `rho` | ESSENTIAL | no gateway investment benefit without it |
| Cross-region friction `tau` | ESSENTIAL FOR OVERLAP MARGIN | distinguishes own from neighbor gateway access |
| Other-region gateway usability `rho-tau>0` | ESSENTIAL FOR GATEWAY OVERLAP | without it, overlap channel disappears |
| Quadratic engagement cost | TRACTABILITY / STABILITY | generates closed-form interior engagement; exact functional form is not yet claimed robust |
| Linear demand | TRACTABILITY | gives closed-form Cournot equilibrium |
| One representative firm per region | TRACTABILITY / APPLICATION | minimal explicit interregional firm rivalry |
| Regional consumer share `CS/2` | MECHANISM-RELEVANT GOVERNMENT OBJECTIVE | sign reversal exists without it, but network necessity no longer holds cleanly |
| Fixed gateway cost `F` | EQUILIBRIUM ONLY | does not affect `Gamma^C`; selects gateway equilibria |
| Baseline profitability `A` | SCALE / EQUILIBRIUM LEVEL | multiplies gross incentives by `A^2` and does not affect their sign |
| Product differentiation | NOT NEEDED | homogeneous goods already generate both signs |

## Product differentiation verdict

**NOT NECESSARY.**

The hard-kill success standard is met without a differentiation parameter. Differentiated Cournot must not be introduced before prior-art re-kill of the homogeneous model.
