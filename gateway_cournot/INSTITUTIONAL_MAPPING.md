# Institutional Mapping — Public Co-Creation Hubs

## Verdict

**PLAUSIBLE FIT.**

The model no longer requires regional hubs to reduce Tokyo/metropolitan participation. It represents regional hubs as infrastructure that lowers firms' cost of engaging with a wider innovation ecosystem, while firms continue to compete in their product markets.

## Mapping

| Model object | Institutional counterpart |
|---|---|
| regional government `i` | prefecture/local government establishing a co-creation hub |
| `E_i` | establishment/operation of regional co-creation gateway |
| `x_i` | firm's intensity of use of external knowledge, matching, partners and innovation ecosystem resources |
| `rho` | own-region hub's reduction in access/search/coordination cost |
| `rho-tau` | weaker access benefit available through another region's hub |
| shared core | metropolitan/national innovation ecosystem and external partner network |
| `beta` | value created by thicker common knowledge/partner/network participation |
| Cournot competition | reduced-form product-market rivalry among beneficiary firms |
| `pi_i` | endogenous product-market profit net of ecosystem-engagement effort |

## Current official evidence

E:N BASE states that it supports new projects/business through member interaction, co-creation events and matching by community managers. Its member page also lists matching support, seminars, workshops, pitches, meetups and use of support schemes. These functions are consistent with an access-cost-reduction interpretation rather than an independent local network replacing the metropolitan core.

Official Ehime procurement for the 2026 metropolitan co-creation event states that issues emerging from E:N BASE activities are taken to metropolitan workshops/events in order to strengthen networks between E:N BASE members and metropolitan firms and generate future mutual collaboration. This directly supports the direction `regional gateway -> metropolitan linkage`.

NEXs Tokyo describes itself as a community linking startups, large firms, municipalities and support organizations nationwide using Tokyo's information and human-network resources. Its DIVE program explicitly supports non-Tokyo startups in accelerating business through access to the metropolitan ecosystem.

## Remaining abstraction

The strongest unvalidated institutional primitive is that another prefecture's gateway lowers a focal firm's ecosystem-engagement cost by a positive amount `rho-tau`. This is plausible for open events, matching and interregional programs, but is not yet a measured structural parameter.

The one-representative-firm Cournot layer is deliberately a minimal competition representation. It should be read as interregional business rivalry, not as a claim that actual E:N BASE members literally compete in one homogeneous-goods duopoly.
