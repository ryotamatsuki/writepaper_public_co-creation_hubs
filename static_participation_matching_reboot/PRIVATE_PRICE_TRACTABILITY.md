# Private Price Tractability

A/B/F: metro demand can be represented as an integral over `(k,z)` conditional on a scalar/fixed-point participation or congestion state. `D_T(p_T)` is plausibly smooth and an interior `p_T*` can be characterized under regularity.

D/E: price tractability is good only in the scalarized versions that fail matching specificity.

C: metro price changes both its own project composition and the assignment shadow values of scarce partner types. Demand is piecewise because capacity constraints bind/endogenously release by type. A scalar closed-form follower best response is not plausibly available without reducing the matching problem to class-specific congestion.

Thus the only strongly matching-specific candidate is also the weakest private-pricing candidate.
