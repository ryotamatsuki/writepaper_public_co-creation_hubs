# Top-Three Minimal Models

Raw scores favor F/B/A, but fatal-reduction rules override scores. For structural diagnosis the three most informative candidates are C, A, and F.

## TOP 1 structural — C: scarce heterogeneous assignment

Projects `(k,z)`; partner types `s`; finite capacities `P_{hs}`; compatibility surplus `g(k,s)`. Each Hub allocates scarce partners across its participating projects. State `Xi_h` is the vector of capacity shadow values / assignment composition. `x_i` expands screening/usable capacity; `p_T` prices metro access. Four-way participation is plausible. Strong stripping passes only if cross-compatible capacity remains, which makes the full game high-dimensional and piecewise.

## TOP 2 — A: bilateral participation

Projects and partners both choose Hubs. `mu_h=mu(x_h,n_h^F,n_h^P)`. This is clean, analytically plausible, and supports non-use, but is isomorphic to two-sided platform participation unless extra matching congestion/assignment is added.

## TOP 3 — F: screening congestion

`e_h=x_h/D_h`, `mu_h=phi_h(k,e_h)`, project payoff `z mu_h-c_h`. This is the cleanest four-way static model, but label stripping produces a standard congested service facility/directed-search problem.

No top-three model qualifies for selection.
