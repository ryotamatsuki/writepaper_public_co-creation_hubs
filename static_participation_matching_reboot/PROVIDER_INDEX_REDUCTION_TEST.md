# Provider-Index Reduction Test

A deterministic index `V_h(omega,x_h)` is fatal when no endogenous other-side/composition state remains.

- A: not provider-only because `(nF,nP)` enters, but the state is generic platform participation.
- B: not provider-only because `D/P` enters, but the state is generic congestion/tightness.
- C: full bilateral assignment cannot be reduced to one provider-only index without solving endogenous capacity shadow values; passes this narrow test.
- D: fails if partner capabilities are abundant/independent because bundle success scalarizes to `mu_h(k)`; otherwise becomes C.
- E: fails. Marginal expected match value is a provider index; cross-provider correlation drops out under single-homing.
- F: not provider-only because demand enters, but state is generic service congestion.

Passing the narrow provider-index test does not imply survival of the strong platform/facility stripping test.
