# Welfare Tractability

For all candidates regional welfare can conceptually be written as resident-project real surplus plus resident-partner real surplus minus `gamma x_i^2/2`.

A/B/F make welfare straightforward but generic platform/search externalities dominate the mechanism.

C requires accounting for opportunity cost of scarce partners and displacement across compatible project types. Correct welfare is naturally expressed using the assignment shadow values, which reinforces both its matching specificity and its analytical complexity.

D with scarce complements requires opportunity costs for each component; E is straightforward because joint structure is irrelevant under single-homing.

Welfare definition is not the binding blocker; the problem is matching-specific strategic tractability.
