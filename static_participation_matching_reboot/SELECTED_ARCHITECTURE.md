# Selected Architecture

**NONE.**

No candidate passes all Stage 3R-PMS GO requirements.

Candidate C is the strongest **diagnostic** architecture because heterogeneous scarce-partner assignment supplies an endogenous matching state that survives label stripping. It is not selected because its minimal genuinely bilateral form is not plausibly tractable for the required `G_1:x_1, G_2:x_2, H_T:p_T` full game. Simplifying it to regain tractability removes the matching-specific state and yields multi-class congestion/provider choice.

Therefore no new Stage 4 static model contract is authorized.
