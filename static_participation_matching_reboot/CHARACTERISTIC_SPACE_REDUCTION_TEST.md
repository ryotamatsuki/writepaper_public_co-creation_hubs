# Characteristic-Space Reduction Test

The Stage 4 CSDS exact Hotelling mapping is avoided by adding endogenous participation/matching states in A/B/C/F. D/E can still scalarize.

But escaping Hotelling is only a first gate:

- A survives Hotelling but becomes two-sided platform competition.
- B/F survive Hotelling but become congestion/directed-search facility choice.
- C survives characteristic-space stripping only in its genuinely heterogeneous assignment version.
- D fails if expected bundle success is a scalar schedule.
- E fails because each marginal expected utility can be written independently of the joint distribution.

**Conclusion:** characteristic-space collapse is not universal, but no candidate survives all subsequent stripping and tractability gates.
