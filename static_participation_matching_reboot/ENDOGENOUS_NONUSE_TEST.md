# Endogenous Non-Use Test

Use project heterogeneity `(k,z)`, with `z` the real surplus available from a successful collaboration.

For any candidate with matching probability `mu_h(k;Xi)>0`, project payoff is diagnostically

`U_h=z mu_h-c_h`, `U_0=0`.

Thus non-use is rational for

`z < z_0(k;Xi)=min_h c_h/mu_h(k;Xi)`.

This creates a positive-measure non-user region whenever the distribution of `z` has continuous mass below the threshold. It is not an artificial atom and it survives small perturbations.

Conclusion: **PASS AS AN ARCHITECTURAL MARGIN.** The earlier CSDS non-use failure was caused by the type-independent positive metro payoff, not by an impossibility of static rational non-participation.
