# Public Best-Response Tractability

A/B/F have plausible public FOCs because each public investment shifts a scalar network/tightness/congestion state. That tractability is exactly why strong label stripping kills them.

C requires differentiating regional welfare through endogenous provider choice **and** an assignment solution with capacity shadow values. Small changes in `x_i` can change which partner constraints bind and the composition of assigned projects. Public best responses become heavily piecewise.

D inherits scalarization or C-like complexity; E is provider-index.

**Result:** no candidate is both strongly matching-specific and plausibly solvable for `BR_i(x_j)` in the mandated full strategic game.
