# Network-Direction Robustness

`beta=0`: fixed-price B3 complementarity disappears; the headline sign reversal fails. Thus the project-to-partner direction is essential.

`alpha=0`: project utility no longer values partner mass, so the two-sided feedback ceases to affect project sorting; P2-R's network component disappears.

Both directions are therefore required for the complements-to-substitutes theorem. The weaker private-price coupling can exist without them.
