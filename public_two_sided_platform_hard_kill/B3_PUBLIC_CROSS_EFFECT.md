# B3 Public Cross Effect

At fixed `p_T`, B3's cross effect comes from the shared private two-sided network, not from private price response.

Mechanism in the central regime:
`x_1 up -> n_1^P up -> n_1^F up -> n_T^F down -> n_T^P down -> q_T down -> region-2 projects move toward H_2 -> marginal value of x_2 rises`.

At the witness `W_{1,x_1x_2}^{B3}=+0.0135412>0`.

At `beta=0`, the shared private-network link disappears and this cross derivative is exactly zero.
