# Mechanical Second-Public Test

**PASS — second public platform is not a one-line replication for P2-R4.**

Adding H2 to Liu/Kim creates a new object: the rival government's marginal incentive and its cross derivative with x1. To obtain P2-R4 one must solve how x1 changes the shared private network, the private fee policy, and the marginal value of x2. This is not available by simply applying the one-public result twice.

Second-public presence itself remains non-novel; only the resulting interaction theorem survives.
