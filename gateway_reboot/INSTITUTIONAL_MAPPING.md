# Institutional Mapping — Co-Creation Hubs

## Verdict

**PLAUSIBLE FIT**, materially stronger than the rejected residual-core-depletion interpretation.

The model does not require regional hubs to reduce Tokyo participation. Instead regional hubs improve access to a shared external ecosystem and can thereby enlarge effective participation in that ecosystem.

## Mapping

| Model object | Institutional interpretation |
|---|---|
| shared core | metropolitan/national innovation ecosystem, with NEXs Tokyo as one concrete component/example |
| `B` | baseline attractiveness/accessibility of the external ecosystem net of direct-access friction |
| `N` | firms effectively connected to the shared ecosystem |
| `beta` | value created by a thicker/diverse network of firms, partners, mentors, investors and information |
| gateway `E_i` | regional co-creation/innovation hub such as E:N BASE |
| `rho` | access improvement from local coordinators, matching, events, consultation and navigation |
| `tau` | extra friction when firms use another region's gateway rather than their own |
| `F` | establishment and operation resource cost |
| `c` | firm-specific cost of ecosystem access/use |

## Primary institutional support

Ehime's official June 24, 2026 metropolitan co-creation procurement states that activities originating in E:N BASE are to be taken to the metropolitan area to strengthen networks between E:N BASE members and metropolitan firms and ultimately create new cross-regional co-creation. This directly supports a gateway/linkage interpretation rather than core depletion.

NEXs Tokyo explicitly uses Tokyo's information and human-network concentration to connect startups from outside Tokyo with firms, local governments, support organizations, partners and mentors, and its DIVE track is for non-Tokyo startups using the Tokyo ecosystem for acceleration.

E:N BASE itself provides matching by community managers, events, workshops, support schemes and facilities. These functions are credible components of `rho`.

## Remaining distance

The strongest abstraction is cross-region gateway usability: the model assumes another region's gateway can partially improve access, whereas actual eligibility, local embeddedness and programme design vary. This is represented by `tau`, but direct measurement is not established.

The additive route bonuses imply that, when a gateway is strictly better, connected firms use that route rather than direct access. This is a deliberate minimal-model simplification, not an empirical claim of literal single-homing.

## Required interpretation discipline

1. Regional hubs do **not** reduce Tokyo participation in the model.
2. Local hubs and the metropolitan/national ecosystem are complements through shared-core thickening.
3. Different regional gateways can still substitute for one another because they offer overlapping access functions.
4. The paper, if it survives Stage 6R, must describe this as an institutional mechanism rather than claim exact structural estimation of `beta`, `rho`, or `tau`.
