# Strategic Feedback Map

## Known B1 feedback

Liu-type public/private competition already gives:

`public action -> public participation -> private participation/network erosion -> private price response -> welfare`.

This is not new.

## Known B2 feedback

Decentralized public-firm theory already gives:

`public action in region 1 -> market allocation -> W_2 -> BR_2`,

and parochial public objectives can reduce aggregate welfare.

This is not new.

## Candidate G-only feedback

The surviving candidate chain is:

`x_1`
` -> (n_1^F,n_1^P)`
` -> (n_T^F,n_T^P)` and `(n_2^F,n_2^P)`
` -> p_T*(x_1,x_2)`
` -> participation on H_2`
` -> W_2`
` -> BR_2(x_1)`.

The reverse chain from `x_2` closes a three-strategic-player network.

The novelty candidate is not that each arrow exists somewhere in prior theory. It is whether the endogenous private price **changes the public-public reaction system** relative to B3 and whether the result depends on regional incidence and cross-side participation.

Stage 4 must therefore compare `BR_i^B3` with `BR_i^G` directly.
