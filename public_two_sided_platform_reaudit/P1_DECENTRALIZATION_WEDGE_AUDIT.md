# P1 — Decentralization Wedge Reversal Audit

Candidate weak statement:

`x^N < x^SP` for weak network effects and `x^N > x^SP` for sufficiently strong cross-side effects.

## Prior-art threats

This weak statement is too generic.

- Belleflamme & Peitz (2010) show that platform intermediation can turn an underinvestment problem into overinvestment because investment changes indirect network effects and access prices.
- Socially conscious/public platform models show welfare rankings that depend on network strength.
- Mixed-duopoly models with network effects show that network strength can change equilibrium strategic choices and welfare.
- Dadpay & Heywood show that decentralized public objectives themselves can create a welfare-reducing strategic interaction.

## Surviving version

Only a theorem of the form

`x_i^N - x_i^SP` changes sign because **regional public business stealing and two-sided network creation interact**, with a threshold that is absent in B1 and B2 separately, remains potentially distinct.

The national private platform need not be essential to this theorem; if the result exists already in B2, it cannot serve as a full-G headline.

## Stage 2 classification

**UNCLEAR — STAGE 3 REQUIRED.**

Generic P1 is weakened/killed. A regional-specific P1 may survive if Stage 3 constructs a minimal architecture in which the wedge decomposition is genuinely different from existing investment/network results.
