# Second Public Platform Essentiality

## What the second public platform does NOT add

It does not make the following novel:

- two-sided network externalities;
- public/private platform competition;
- public-platform entry;
- network fragmentation;
- critical mass;
- the fact that multiple platforms can lower welfare;
- the fact that multiple public firms can interact strategically.

## Potentially essential role

A second regional public platform creates a distinct strategic object only if `G_1` and `G_2` maximize **different regional welfare functions** and one government's platform-building action changes the other's incentives through both direct participant migration and the national private platform's endogenous response.

That object is absent from one-public B1 by definition.

## Stage 2 verdict

**POTENTIALLY ESSENTIAL, NOT PROVEN.**

Stage 3 must reject any architecture in which the second public platform merely duplicates a symmetric private-platform equation or where all results can be obtained from B1 by replacing `n=1` with `n=2`.
