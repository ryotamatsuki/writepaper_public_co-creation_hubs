# Minimal Causal Chain

## Fixed-private-price benchmark B3

`regional public facilitation`
→ `focal project allocation`
→ `cross-side partner/network participation`
→ `rival regional marginal return to public investment`
→ **positive public-public strategic interaction can arise**.

## Full game G

`regional public facilitation`
→ `private-hub demand`
→ `private-hub repricing`
→ `project and partner reallocation in both regions`
→ `rival regional marginal return to public investment`
→ **negative price-mediated contribution can dominate the positive fixed-price network channel**.

The essential comparison is not “network effects versus pricing” in the abstract. It is the nested change in the same public-public best-response object when the third actor's optimizing price response is switched on.
