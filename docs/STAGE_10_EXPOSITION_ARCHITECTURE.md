## Figure decision

**NO REQUIRED FIGURE.**

This remains a deliberate architecture decision. The central analytic result is a local existence theorem without a certified primitive formula for the endpoint `epsilon`; plotting an arbitrary continuation path or normalized sign index would risk communicating a global threshold/regime map that the theory does not establish. The repaired numerical result is now explicitly only one-vector search evidence, making a path/surface figure even less appropriate. The welfare result is likewise a local derivative plus a two-state numerical comparison.

A game-timing diagram remains nonessential: the four-step timing is short, linear, and already stated explicitly in the Model section. No diagram materially reduces cognitive load relative to the prose.

A future quantitative figure becomes admissible only if an earlier stage is formally reopened and verifies an actual economic object over a nontrivial domain, such as a certified comparative-static path or threshold/regime map. Stage 11R must not manufacture such a domain for exposition.
